# 产品与范围

## 1. 产品定义

这是一个**教师工作台的移动端高保真 Demo**，用于演示信息架构、视觉风格与触控交互，不是完整业务系统。

- 语言：简体中文。
- 主要设备：手机竖屏；桌面端仅以手机容器预览。
- 技术形态：零依赖原生 HTML、CSS、ES Modules，无构建步骤。
- 登记页、安排页与统计页均为可操作的本地业务 Demo：网格、座位、班干、值日与课程成绩共享同一份学生名单；登记另含作业、提交、分数和座位数据；安排另含周课表；统计另含登记汇总矩阵、多场考试与独立于作业分的科目成绩。统计页考试子视图通过顶栏考试名与顶部考试列表 Sheet 切换/管理考试，并支持表头/姓名列冻结、按科排序与成绩统计浮层；作业子视图以只读矩阵展示全部作业的登记状态，改分仍回到登记页。46 个姓名仍是 Demo 占位名单，不代表真实学生；除非任务明确要求，不得虚构真实成绩、学校或业务数据。

## 2. 固定信息架构

主导航固定为 3 页，每页固定 2 个子视图：

| 页索引 | 主页面 | 子视图 0 | 子视图 1 |
| --- | --- | --- | --- |
| 0 | 安排 | 人员（班干 + 值日） | 课表 |
| 1 | 登记 | 网格 | 座位 |
| 2 | 统计 | 作业（登记汇总矩阵） | 考试（考试成绩） |

刷新后的初始状态：

- 当前主页面为索引 `1`（登记，中间页）。
- 三个页面的子视图均为索引 `0`。
- 设置页、更多菜单与字号浮层关闭，Toast 隐藏。
- 导航与子视图不恢复上一次状态。
- 学生姓名字号默认 `16px`；若存在有效持久化值，则恢复为上次选择的 `14～18px` 字号。

## 3. 固定界面区域

从上到下：

1. 顶栏：左侧“设置”、居中标题、右侧“更多”。安排页标题为「安排」；登记页标题为当前活动作业名称（右侧向下箭头，文字几何居中），点击打开作业列表；统计页作业子视图标题为「统计」，考试子视图标题为当前考试名称（同款箭头），点击打开考试列表。设置按钮进入独立全屏设置页；更多按钮或底部上滑打开当前页面的上下文动作底部 Sheet。
2. 内容视口：3 个可横向切换的页面；每页自身可纵向滚动。
3. 底部主导航：用 3 个图标分别进入安排、登记、统计，并保留子视图指示点；用户主动进入座位横屏模式时临时隐藏，退出后恢复。
4. 登记浮层：作业列表与学生记录面板互斥；学生记录与课程成绩计分 Sheet 内提供「整十」开关；登记上下文动作位于“更多”底部 Sheet，包含快速打分、新建作业、清除当前作业与姓名字号，网格和座位视图共享同一姓名字号控制。“更多”顶部固定提供深浅色切换与打开设置，底部固定显示当前子页面的清除项。
5. 安排页与统计页浮层：安排页课表相关 Sheet（课表格、节次改名、高亮科目）互斥；统计页考试列表（含考试名称二级层）与成绩/统计相关 Sheet 互斥。安排页上下文动作位于“更多”底部 Sheet，人员子视图同时提供新增班干、新增值日、清空班干指派与清空值日安排，课表子视图提供清空本周课表与高亮科目；统计页上下文动作位于“更多”底部 Sheet，考试子视图包含新增科目、新增考试、成绩统计与清空本场成绩，作业子视图只读、不提供新增业务动作。
6. 设置页：由顶栏设置按钮或「更多」底部 Sheet 的「打开设置」入口进入的独立全屏界面，提供深浅色切换、「学生名单」全屏编辑入口，「表格数据」导入/导出，以及「JSON 备份」导入/导出。表格数据导出为按类型分工作表的 XLSX，用于查看、修改与数据交换；导入兼容 XLSX 和旧 CSV。JSON 用于原样备份。导入均在确认后一次性替换全部业务数据，不提供合并。内部状态字段仍称 `drawerOpen`。学生名单编辑为叠在设置之上的独立全屏页（非 Sheet、非主 Tab），与设置页共用全屏进入/退出动画、左滑关闭手势和顶栏样式；支持新增、改名与删除（至少 1 人、至多座位容量），改名/新增时可指定姓名首字母（未手动指定则按姓名自动推导并持久化，登记页字母索引据此定位）；返回后仍显示此前打开的设置页。
7. 临时反馈：顶部 Toast。

### 3.1 表格工作簿

表格导出面向日常查看、批量登记和修改，版本 3 固定生成以下六个工作表：

| 工作表 | 主要用途 | 可修改内容 |
| --- | --- | --- |
| 座位表 | 复刻 8×13 座位和讲台方向 | 仅显示座位表；名单与编号作为隐藏交换数据 |
| 作业登记 | 按学生登记作业 | 作业名称、空白、`✓`、0～100 分数；C 列起作业项全部居中 |
| 班干安排 | 查看和编辑班干 | 名称和一个成员序列单元格 |
| 值日安排 | 查看和编辑值日 | 名称、说明和一个成员序列单元格 |
| 课程表 | 查看每周课程 | 节次名称和科目文字 |
| 考试成绩 | 按考试和科目登记成绩 | 考试名称、第一场考试的科目名称和 0～100 成绩 |

「座位表」可见区域 A1:M10 只显示座位表：A2:M9 按 `seatIndex` 行优先显示全部 104 个位置，空位不折叠，姓名竖向排列；A10:M10 合并显示「讲台」。打印区域固定为 A1:M10，并按竖向 A4 单页适配。名单和稳定学生编号保存在隐藏行列中。班干和值日成员单元格只显示姓名，多个成员以「；」分隔，反斜杠和分隔符按规则转义；空单元格表示没有成员。

工作表中的隐藏行列用于保留版本、数量和内部编号。用户在应用内新增或删除学生、作业、班干、值日、节次、科目和考试，再重新导出工作簿；手工导入要求隐藏座位名单行、作业列、班干行、值日行、考试列和科目列完整保留。导入按版本/工作表路由：版本 2 的「学生名单」「作业登记」「人员安排」「课程表」「考试成绩」五表、版本 1 的十二工作表 XLSX 与旧 CSV 继续用于导入；个人新增工作表会被保留并忽略。

## 4. 修改边界

除非需求明确要求，否则：

- 不增加登录、后端、路由、网络请求或云端设置系统；本地业务持久化与主题仅按交互和工程文档规定的键名、Schema 与回退策略实现。
- 不改变主页面数量、顺序和子视图数量；主页面名称与子视图分段随信息架构演进可调整（当前为「安排 / 登记 / 统计」，见 §2）。登记页当前不显示分段控件，通过重复点击底部“登记”切换网格 / 座位。
- 不将 Demo 擅自改成后台管理页、卡片瀑布流或桌面 Dashboard。
- 登记范围内的完成、计分、作业、座位编辑与批量操作必须有明确的取消、清除、交换、复位或确认路径。
- 不添加品牌 Logo、插画、照片或装饰性 emoji；主题仅可通过既有语义 token 覆盖浅色基线。
- 允许持久化学生姓名字号、业务数据、主题和课表高亮关键词；导航、子视图、设置页、更多菜单、其它浮层、座位编辑模式、快速打分模式、整十模式和画布 transform 始终在刷新后重置。

## 5. 内容写作规则

- 标题短而直接；按钮优先使用 2～6 个汉字。
- 辅助文字说明“是什么/将做什么”，避免营销口号和空泛形容词。
- 同层级文案保持平行结构。
- Sheet 标题分层：小字为稳定类型/场景，大字为本次对象或动作；二者不叠写同义词；标题下说明只写后果，不复述界面操作。
- 确认面板：小字固定「确认」，大字用祈使或名词短语且不加问号；正文点名具体对象（作业名、职位名等）。
- 占位内容明确标注“占位”“待完善”或“即将推出”，不可伪装为已完成能力。
- 不使用英文作为主要操作文案；页面眉题中的现有英文标签可以保留。

## 6. 文档优先级

发生冲突时按以下顺序处理：

1. 用户当前任务中的明确要求。
2. 与改动职责对应的现行文档：`product.md`、`visual-design.md`、`interaction.md`、`engineering.md`。
3. [`architecture.md`](architecture.md)。
4. [`glossary.md`](glossary.md)。
5. 当前实现。
6. `archive/` 中的历史档案。

现行文档未覆盖某项时，不进行猜测式重设计：保留现状并做满足需求的最小改动。完整冲突处理规则见 [`README.md`](README.md)。

# 交互与状态

## 1. 状态模型

状态分为 UI 瞬时状态与业务 Store 两个边界。`src/scripts/state.js` 只保存 UI 状态：

```text
currentPage: 0 | 1 | 2
subviews: [0 | 1, 0 | 1, 0 | 1]
drawerOpen: boolean
studentFontSize: 14 | 15 | 16 | 17 | 18
fontSizePopoverOpen: boolean
seatEditing: boolean
seatLandscape: boolean
activeOverlay: null | 'assignments' | 'exams' | 'student-record' | 'people-pick' | 'people-edit' | 'course-slot' | 'course-period' | 'course-subject' | 'course-grade' | 'course-stats' | 'course-highlight' | 'confirm' | 'roster-editor' | 'more'
gradeExamId: number | null
gradeSort: null | { subjectId: number, direction: 'asc' | 'desc' }
```

`roster-store.js` 是学生、座位、作业、提交、分数、班干、值日、课表、考试与课程成绩的唯一可写来源；网格、座位、人员与课程渲染器只订阅它，禁止双写领域数组。

约束：

- `currentPage` 必须经过 `clampPage()`，不可越界。
- 每页独立记住本次会话中的子视图选择。
- 导航、子视图、设置页、姓名字号、当前考试与成绩排序状态只存在内存；刷新后回到产品文档定义的初始状态。
- `gradeExamId` 为 `null` 时渲染层回退到第一场考试；`gradeSort` 不持久化。
- `studentFontSize` 使用 `teacher-workbench.student-name-font-size` 保存；读取失败或非数值时回退到 `16`，越界数值按 `14～18` 夹取。业务数据和主题的受控持久化规则见工程文档。
- CSS class 和 CSS 自定义属性是状态的渲染结果，不是第二份状态源。

## 2. 主页面导航

用户可通过两种方式切换主页面：

1. 点击底部的另一个导航项，直接进入目标页。
2. 在内容区水平拖动，按内容轮播方向切换相邻页；在底部导航上水平拖动，则直接操控三段式 glider 选择相邻页。顶栏与内容视口、底栏同属切页手势表面：顶栏及其可点控件使用 `touch-action: none`，避免浏览器中途 `pointercancel` 打断横滑。

主页面横滑跟手与 CSS 落位期间，`#app` 加上 `is-page-gesturing`，关闭顶栏 `backdrop-filter`（与 Sheet 的 `is-sheet-gesturing` 同理），避免页轨移动时每帧重采模糊背景。跟手帧按动画帧合并写入 `#pages` / `.nav-glider` 的 `transform`。

当前导航项被再次点击时，不停留不动，而是切换该页的两个子视图。这是既定功能，不能“修正”掉。

每次渲染必须同步：

- `.pages` 的横向位置。
- `.nav-glider` 的位置。
- 顶栏标题：人员页显示页面名称；登记页始终显示当前活动作业名称，并在标题文字右侧显示向下小箭头（左侧等宽占位，文字仍居中），提示可点击打开作业列表；课程页课表子视图显示「课程」，成绩子视图显示当前考试名称并带同款下拉箭头，提示可点击打开考试列表；从其他页面切回时必须立即刷新，不得保留上一页标题。
- 导航按钮 `.active` 和 `aria-current="page"`。
- 存在分段控件的页面中，segment 的 `.active`。
- 每页 subview 的 `.active`。
- 每个导航项的子视图指示点 `.on`。

## 3. 子视图

- 点击分段按钮只切换其所属页面的子视图，不切换主页面。
- 在分段控件轨道内横滑只切换子视图（驱动分段滑块），不切换主页面。分段轨道与按钮使用 `touch-action: none`，避免浏览器取消中途打断子视图横滑。
- 人员页和课程页始终恰好 1 个 segment 与 1 个 subview 为 active。
- 登记页不显示 segment，重复点击当前“登记”导航项在网格 / 座位间切换，并由 subview 与指示点表达状态。
- 切换主页面后，该页恢复到本次会话最后选择的子视图。

## 4. 登记业务交互

- 活动作业属于业务 Store。网格和座位卡的轻点只切换当前作业的完成状态；完成与分数按 `(assignmentId, studentId)` 唯一，分数存在即视为完成。
- 长按约 `480ms`、桌面右键打开同一学生记录；移动超过 `9px`、结束、取消或离开均取消长按，成功长按必须抑制同一指针序列的 click。成功长按使用触觉反馈（见「触觉反馈」）。
- 长按打开学生记录即视为打分意图：面板直接显示学生姓名、分数框和内置数字键盘，不再提供二次模式选择或唤起系统软键盘。键盘支持 `0～9`、小数点和退格，只允许形成 `0～100` 且最多一位小数的草稿；底部「取消」和右上角关闭按钮均只关闭 Sheet、丢弃本次草稿，「保存」写入分数并关闭；不提供单条记录清除入口。仅提交仍由网格或座位卡轻点完成。学生记录打开后可在除输入框外的全屏区域纵向拖动跟手关闭/回弹，自滚动区域未到边时优先滚动。
- 顶栏登记标题显示活动作业名称，点击打开作业列表（从上往下弹出）；在登记页网格视图下，全屏（顶栏、主内容区、底栏）下滑可打开作业列表，座位视图与其他页面不响应该打开手势。列表显示已交人数/总人数，支持选择、新增、重命名和删除，至少保留一个作业。删除活动作业后选择相邻可用作业。
- 改名与新增均使用作业名称（二级顶部 Sheet）：标题小字「作业」，改名大字「修改名称」、新增大字「新增」；字段标签「名称」；改名预填当前名称、主按钮为「保存」；新增为空输入、主按钮为「添加」。取消/点遮罩或 Escape 关闭；打开后全屏纵向跟手关闭（输入框上除外），松手按进度/甩动落位；Enter 提交；校验失败以 Toast 提示。输入法弹起时，取消/保存（添加）须在 `pointerdown` 立即生效，并短暂吞掉随后的幽灵点击；新一次 `pointerdown` 必须立即解除该保护。删除须经确认面板：标题「删除作业」，确认后以 Toast 提示；禁止使用系统 confirm / prompt。关闭作业列表时须先关闭作业名称。Escape 优先关闭作业名称，再关闭作业列表。
- 作业列表标题为小字「登记」+ 大字「作业」。
- 系统输入法弹起时：顶栏、底栏、页面与其它未聚焦浮层保持布局高度与位置；仅包含当前文本输入的浮层按 Visual Viewport 收缩底部（`--ime-inset-bottom`），不得连带压矮整壳。
- 顶栏“更多”按钮或底部上滑打开上下文动作 Sheet；全屏设置页提供深浅色切换、名单与备份入口。主题切换立即应用并写入既有受控主题键；「导入备份」从 JSON 文件读取业务数据并替换整个 Store；「导出备份」将当前业务数据导出为带格式版本号的 JSON 文件，优先调用 Web Share API 分享，失败时回退到 Blob 下载。设置右下角展示只读内容指纹与生成时间（UTC+8，精确到秒），供对照源码/LAN/APK 版本；打开时刷新，不可点击、不进入关闭栈。
- 登记页网格与座位均提供右侧姓名首字母索引：默认显示纵向居中短滑块（指示条）；任一触摸（轻点、按住或纵向拖动）必须在同一输入回合立即触发完整字母条，指示条侧滑渐隐，字母条以约 120ms 渐变 + 自右侧侧滑显示（字母水平居中）并显示大号字母徽标，并以课表「高亮科目」同款淡蓝弱强调命中学生格与座位卡；切换字母时轻触反馈；松手后完整字母条、徽标与高亮继续保留约 `400ms`，再由字母条侧滑渐隐、指示条侧滑渐显收回。无匹配字母可滑过但不点亮学生。索引手势不得触发主页面切页、作业列表打开或座位画布平移。
- 字母索引默认隐藏；仅主页面**稳定落在登记页之后**才渐变出现（切页 CSS 过渡约 `420ms` 结束后再显示）。主页面一旦出现横向位移（内容区或底栏跟手 / `renderDrag`），索引立刻快速渐隐并中断进行中的按住高亮；落稳后若仍在登记页再渐显，落在人员/课程则保持隐藏。登记页内网格↔座位切换不因此隐藏索引。字母索引显隐为 UI 瞬时态，不持久化。

## 4.1 人员业务交互

- 班干与值日列表由业务 Store 驱动；每项独立卡片展示。轻点行打开学生选择 Sheet（小字「班干」/「值日」，大字为该项标题），可多选草稿指派；浮层内提示「已选 N 人」或「未选择」；点选条目切换勾选且不关闭 Sheet；「清除」只清空草稿，「确认」才写入 Store 并关闭；关闭/遮罩/Escape 丢弃草稿。列表未指派分别显示「未指定」「未排」，已指派姓名完整换行展示（中文顿号连接）。学生名单由脚本接管纵向滚动（`touch-action: none`，松手可走既有惯性）；与其它 Sheet 列表相同：同一手势内滚至顶缘后不关闭，须松手后再一次下滑才跟手关闭 Sheet；已在顶缘时直接下滑仍可关闭。把手/标题等非列表区域仍可随时跟手关闭。
- 长按约 `480ms` 或桌面右键打开编辑 Sheet（顶部输入 Sheet，小字「班干」/「值日」，大字为该项标题，说明「删除后不可恢复。」）：班干改职位名，值日改星期标题与任务说明；文案上限 40 字；提供删除，班干与值日各自至少保留 1 项，删除须经确认面板（标题「删除班干」/「删除值日」，不加问号）。输入法弹起时，取消/保存/删除须在 `pointerdown` 立即生效，并短暂吞掉随后的幽灵点击（避免点到确认遮罩/取消而误关）；新一次 `pointerdown` 必须立即解除该保护。
- “更多”菜单：人员页班干子视图显示「新增班干」「清空班干指派」；值日子视图显示「新增值日」「清空值日安排」。新增默认标题为「新班干」「新值日」。清空指派须经确认（标题「清空班干指派」/「清空值日安排」），不清空职位/值日项本身。
- Escape / 系统返回优先关闭确认面板，再关闭人员编辑 Sheet、学生选择 Sheet，再进入既有关闭栈。

## 4.2 课程业务交互

- 课表为周一～周五、每日固定 10 节（默认列标：早、1～4、午、5～7、服；完整名可在改名 Sheet 中编辑）；节次结构不可增删。课表矩阵须在课程页一屏内完整显示、无需纵向滚动。轻点格打开课表格 Sheet（顶部输入 Sheet，小字「课表」，大字「周X · 节次」）编辑科目文案（≤40 字）或清除；长按节次名打开节次改名 Sheet（顶部输入 Sheet）。课表格与节次名上的横滑须能触发主页面切页（不得因防误触 Sheet 跟手而整段 `blocked`）；有效横滑后抑制本次 click，轻点仍打开编辑。课表格/节次/科目 Sheet 的取消、保存、清除在 `pointerdown` 立即生效并短暂吞掉幽灵点击；关闭瞬间须暂时阻断下层课表与导航命中，避免同一手指残留触发格子 `:active` 按下闪。
- 成绩表按当前考试列出全部学生与科目列；表头冻结首行，姓名列冻结首列（横向滚动时保持可见）。当前考试由顶栏标题表达：成绩子视图下顶栏显示考试名+下拉箭头，点击打开考试列表（从上往下弹出的顶部 Sheet）；在成绩子视图中，顶栏、底栏与成绩表均可下滑跟手打开考试列表。成绩表滚动区（`.grade-scroll`）内：可滚方向由脚本接管双轴滚动（`touch-action: none`，横滚与纵滚松手均可走既有惯性），横纵方向溢出时分别显示轻量滚动指示条；同一手势内滚至边缘后不交接；须松手后下一次手势才从顶缘下滑打开考试列表，或从左/右缘横滑切主页面（无横向溢出时横拖仍可直接切页）。考试列表标题为小字「课程」+ 大字「考试」；每行显示考试名与「已录入 X/Y」，支持选择、新增、改名和删除，至少保留 1 场；删除须经确认面板（标题「删除考试」，文案「将删除「X」及其全部成绩记录。」）；删除当前场后回退到第一场。改名与新增均使用考试名称（二级顶部 Sheet）：小字「考试」，改名大字「修改名称」、新增大字「新增」；字段标签「名称」；改名预填、主按钮「保存」；新增空输入、主按钮「添加」；提示语对齐作业名称 Sheet。取消/点遮罩或 Escape 关闭；打开后全屏纵向跟手关闭（输入框上除外）；Enter 提交；校验失败以 Toast 提示；输入法弹起时取消/保存（添加）须在 `pointerdown` 立即生效并短暂吞掉幽灵点击。关闭考试列表时须先关闭考试名称。Escape 优先关闭考试名称，再关闭考试列表。「更多 → 新增考试」关闭更多菜单后直接打开考试名称（新增）Sheet，与列表内「新增考试」同一套校验与落库；新增后不自动切换当前考试。轻点分数格打开成绩 Sheet（底部 Sheet，小字为「考试名 · 科目名」，大字为学生姓名）与内置数字键盘，版式与登记页学生记录计分 Sheet 对齐（状态行、大号分数、键盘与清除/保存）；规则与登记计分相同（`0～100`、最多一位小数）；数字键轻点录入，从数字键盘区域下滑时须与登记计分 Sheet 一样驱动 Sheet 跟手关闭而不录入；可清除单格。课程成绩与登记作业分数完全独立。轻点科目列头循环排序：降序 → 升序 → 恢复名单顺序；未录入恒沉底；排序为会话瞬时状态。成绩表在同一滚动端口内同时承载纵滚与横滚，表头 sticky 冻结首行、姓名列 sticky 冻结首列。保存/清除/关闭须在 `pointerdown` 立即生效，并只吞掉同一指针序列随后落在底栏、分段或成绩格上的幽灵点击，避免误切到课表或其他主页面；新一次 `pointerdown` 必须立即解除该保护，不得吞掉用户下一次底栏操作。
- 长按科目表头打开科目编辑 Sheet（顶部输入 Sheet）：可改名或删除；至少保留 1 个科目，删除须经确认（标题「删除科目」）。
- “更多”菜单的「成绩统计」打开底部统计 Sheet（小字「统计」，大字为当前考试名），按科目展示平均分、最高分、最低分与已录入人数；全空显示「未录入」。
- “更多”菜单：课程课表子视图显示「清空本周课表」「高亮科目」；成绩子视图显示「新增科目」「新增考试」「成绩统计」「清空本场成绩」。新增科目默认「新科目」；新增考试关闭更多菜单后直接打开考试名称（新增）Sheet。清空课表/本场成绩须经确认，不清空节次、科目或其他考试。
- 「高亮科目」打开顶部 Sheet：用顿号/逗号/换行配置关键词（字符串包含匹配，大小写不敏感）；命中的已填课表格使用淡蓝弱强调，不得使用高饱和大块色。关键词写入 `teacher-workbench.highlight-subjects`，不进入业务 Schema。
- Escape / 系统返回优先关闭确认面板，再关闭课程相关 Sheet（高亮科目 → 成绩统计 → 考试名称 → 考试列表 → 科目编辑 → 节次改名 → 课表格 → 成绩），再进入既有关闭栈。

## 5. 姓名字号

- 登记页从“更多”菜单选择“调整姓名字号”；网格和座位视图共用同一个姓名字号 Popover。选择后关闭更多菜单并打开 Popover；再次点击顶栏更多按钮或点 Popover 外部可关闭。
- “更多”菜单始终提供登记视图切换：网格视图显示「切换至座位视图」，座位视图显示「切换回网格视图」并另提供座位编辑与复位；另提供「新建作业」「清除当前作业」与「调整姓名字号」。人员页只提供按子视图的班干/值日操作（新增、清空指派）；课程页只提供按子视图的课表/成绩操作（清空课表、高亮科目、新增科目、新增考试、成绩统计、清空本场成绩）。
- 字号滑杆范围为 `14～18px`、步长 `1px`，拖动和键盘调整时实时更新网格与座位视图的学生姓名及数值输出；座位姓名按画布基准字号映射，缩放画布时继续随画布缩放。
- 每次有效调整立即写入持久化；刷新后恢复上次字号。
- 点击姓名字号外部、切换页面 / 子视图或按 `Escape` 时关闭；浮窗打开时点外部的首次点击只关闭浮窗（该按压全程底层不可命中），同一击不触发浮窗下的控件、不呈现其按压视觉，第二次点击才正常生效；滑杆手势不得触发横向切页。
- 姓名字号开关不持久化，刷新后始终关闭。

## 6. 座位画布与编辑

- 座位表包含 13×8、共 104 个逻辑位置，仅渲染 46 张已安排学生卡；学生与座位索引必须来自业务 Store 的同一份数据。座位卡可访问名称须包含学生姓名、完成/分数状态及从 1 开始的排、列位置。
- 查看模式按当前座位映射压缩完全空置的逻辑行列，但保留过道与座位相对关系；默认缩放优先保证座位卡约 44px 的触控尺寸，窄屏允许少量横向平移。轻点、长按/右键与网格等价；键盘激活座位卡等价于轻点登记。从卡片拖动转为画布平移，空白区域用于平移，双指与滚轮用于缩放；平移与双指缩放的命中范围覆盖整个座位视口（含舞台缩放后四周留白），均不得触发主页面导航。
- 编辑模式展示完整 13×8 网格并持续显示「编辑中」状态条和「退出」按钮。轻点座位卡只选择学生，不切换完成状态；长按/右键不打开学生记录。拖到空位移动，拖到占用位置交换；状态条须在拖动时区分「移动到第 N 排第 N 列」与「将与某学生交换」，完成后 Toast 使用对应结果文案。
- 编辑模式支持键盘闭环：激活座位卡选择学生，方向键在 13×8 逻辑位置中移动目标，Enter 确认移动/交换，Escape 取消选择；也可选择学生后将焦点移到另一张座位卡并按 Enter 直接交换。源座位与目标位置均须有可见焦点/高亮，提交后焦点跟随被移动学生。
- 查看和编辑模式均提供「适应」按钮。进入或退出编辑模式时按对应画布重新计算默认位置和缩放；显式复位执行同一操作。画布 transform 与编辑模式仅在当前会话中保留，刷新后恢复查看模式和默认画布。快速平移可有惯性，reduced-motion 下跳过惯性。
- 查看模式右下角提供「全屏」入口，必须由用户主动触发；进入后请求设备横向，隐藏应用顶栏与底部主导航，姓名改为横向排列，并按横向座位比例重新适应、回中。方向或视口尺寸变化后再次自动适应、回中；只有系统窗口或 Web 视口确认已变为横屏后才切换专用界面，方向请求失败时保持原界面并明确提示，禁止使用只旋转 Web 内容的伪横屏兜底。浮动入口改为「退出全屏」；Escape / Android 返回键优先退出全屏。编辑模式禁用该入口。全屏状态不持久化。
- pointer up、cancel、lost capture、模式切换和卸载必须清除临时 transform、选择与目标高亮。

## 7. 水平与垂直手势

轴锁定规则：移动超过 6px 后，以绝对位移较大的方向锁轴，本次手势中不再改变。

### 防复发：`touch-action` 与浏览器抢手势

外壳（`#viewport`、`.page`、顶栏、底栏、分段等）与脚本接管的滚动面必须使用 `touch-action: none`，由 Pointer Events + `preventDefault` 驱动跟手，**禁止**在仍与切页 / Sheet 跟手共享指针的表面上写 `pan-x` / `pan-y` / `pan-x pan-y`（含 CSS 与运行时 `style.touchAction`）。

否则浏览器会在拖动中途接管默认平移并 `pointercancel`，表现为「页面或表格刚移动一小段就被打断」。成绩表（`.grade-scroll`）已多次因此回归（含渲染器按溢出动态写入 `pan-*`）。人员选择名单已纳入脚本滚动与 Sheet 边缘交接，不再使用 `pan-y`。

### 水平拖动

- 内容区横拖时页面实时跟手，glider 同步指向将进入的页面，且均不播放 transition。
- 底部导航横拖时 glider 以 1:1 位移跟随手指，内容页按“滑块跨一段对应内容跨一页”的进度实时联动；向左拖选择前一段，向右拖选择后一段。每当最接近的段索引变化时触发一次触觉反馈（边缘夹取后不重复震）。
- 人员页与课程页的分段控件（`.segments`）内横拖只操控 `.segment-glider`，不得触发主页面切页；规则对齐底栏：1:1 跟手、边缘阻尼、松手按最近段落位，段位变化时轻触反馈。点击分段按钮仍可直接切换子视图。
- 点击底栏导航按钮（切页或登记页重复点击切换子视图）触发一次触觉反馈。
- 第一页向右、最后一页向左时应用边缘阻尼，不能露出空白页。
- 底栏 glider 在第一段继续向左、最后一段继续向右时应用同样的边缘阻尼。
- 松手后根据距离或快速甩动决定是否切换；内容区最多切换相邻 1 页，底栏按滑块松手时最接近的段位落位，并允许一次横跨首尾页。
- 未达到阈值时回弹到当前页。
- 成绩表有横向溢出时，端口内横拖由脚本滚表且不切主页面；已在左/右缘且本势从该缘起滑时，须松手后再一次横滑才切页（无横向溢出时横拖仍可直接切页）。
- 全屏设置页呈现且为最上层时，页内横滑（手指向左）直接驱动设置页向左 1:1 跟手，等效关闭手势；手指向右不驱动（避免误抢点击）。跟手期间遮罩透明度与面板位移 1:1 变化，面板右缘投影随面板移动，帮助看清层级移动。松手按位移/甩动决定关闭或回弹；确认关闭后面板在 `-100%` 基础上继续补走 `--shadow-sheet-right-clearance` 的阴影清除距离，让右缘投影自然离开视口，且遮罩与面板仍使用相同时长、相同缓动收尾；关闭落位开始后设置页立即退出命中并解除外壳 `inert`，动画继续完成——遮罩完全消失的时刻即面板完全移出、下层已可点击。手势关闭后紧随的第一次轻点由手势路由直接激活，不依赖 WebView 是否合成 click。跟手期间设置页头部关闭 `backdrop-filter`。

### 内容区垂直拖动

- 默认纵向移动当前 `.page` 的 `scrollTop`，不触发横向切页。
- 登记页网格视图：在应用全屏表面（顶栏、主内容区、底栏）向下拖使作业 Sheet 与遮罩跟手滑入，向上拖使“更多”Sheet 与遮罩跟手滑入。松手后按进度/距离/甩动决定落位或回弹；打开作业不加振，手势打开更多使用轻触反馈。
- 成绩表（`.grade-scroll`）纵滚由脚本接管；与打开考试列表/“更多”Sheet 的边缘交接规则见 §4.2。
- 浏览器不得在手势中途接管并取消 pointer 序列。

### 纵向 Sheet 全屏跟手

- 适用范围（均为 `translateY` Sheet，与 `src/scripts/overlay-stack.js` 派生的 `SHEET_STACK_ORDER` 一致）：确认面板、高亮科目、成绩统计、考试名称、考试列表、课程科目/节次/课表格/成绩、人员编辑、人员选择、作业名称、作业列表、学生姓名、学生记录、更多菜单。姓名字号 Popover 不在此列；全屏设置页使用独立的横向跟手（见「水平拖动」）。
- 任一上述 Sheet 呈现时：除自滚动容器（且该方向尚未到边）与文本输入控件外，全屏任意位置均可纵向拖动，实时驱动该 Sheet 的 progress（0～1）与遮罩透明度；把手不再是唯一关闭入口。每个 Sheet 必须使用控制器注入的真实 `.sheet-scrim` 作为遮罩命中层，遮罩轻点关闭也只通过控制器的 `onRequestClose` 契约进入业务关闭函数，禁止业务模块再以外层 `event.target` 自行判断。
- 嵌套滚动（业界 Sheet 惯例）：列表可滚时优先滚列表；仅当该方向已到边，且手指继续沿关闭向移动时，才把跟手交给 Sheet。凡脚本接管的列表滚动口（含作业/考试列表及其他 Sheet 内 JS 滚动面）：在同一手势内滚至边缘后，须松手再下一次滑动才关闭 Sheet；列表已在关闭向顶缘时直接滑动仍可跟手关闭。顶部 Sheet（作业列表/作业名称、考试列表/考试名称、课表格/节次改名/科目编辑/高亮科目/人员编辑）关闭向为上滑，底部 Sheet 关闭向为下滑。已完全打开时，打开向的过量拖动不得再驱动 Sheet（避免误抢点击与空跟手）。
- 所有参与 Sheet 跟手的滚动面与真实遮罩须 `touch-action: none`（含高亮科目面板和人员选择名单，见 §4.1），避免浏览器接管纵向手势后触发 `pointercancel`。文本 Sheet 外壳可保留 IME 所需的点击策略，但不得承担遮罩命中；文本输入控件由手势路由直接排除，轻点聚焦和 IME 输入不认领为 Sheet 拖动。
- 多层同时存在时只驱动最上层（顺序与返回键关闭栈一致，见 §10）；同一次手势不转移到下层。
- 松手：已打开 Sheet 慢拖关闭须位移约 `max(180px, 行程 40%)`；快速向外甩动时结合速度与惯性，短距离（约 36px+、关闭向速度约 `0.4px/ms`）亦可关闭。打开态按约 34% / 58px / 甩开阈值。`pointercancel` 等中断时已打开 Sheet 回弹。面板/列表/遮罩用 `touch-action: none`，列表滚动由脚本接管。落位用 CSS transition；`prefers-reduced-motion: reduce` 时直接到位。跟手位移与遮罩透明度、列表 `scrollTop` 均按动画帧合并绘制（面板用 `translate3d`），避免每 pointermove 重复触发布局或整树样式失效。
- 页面与普通 Sheet 隐藏系统滚动条；作业、考试与人员相关列表溢出时使用统一细滚动条，且仅在滑动（或桌面悬停）时短暂出现（见 [`visual-design.md`](visual-design.md)）。`overscroll-behavior: contain` 与 JS 惯性（成绩表双轴滚动、Sheet 列表）保持一致。
- 有纵向 Sheet 呈现或跟手进行中时，禁止横向切页。
- 手势打开的 Sheet 关闭/取消时不得把焦点还回顶栏标题；程序化焦点使用静默聚焦（不显示 `:focus-visible` 环）。半程回弹落位不得再次触发打开时的抢焦点。

### 底部导航上滑

- 底栏上滑可打开“更多”Sheet；登记网格下底栏下滑可打开作业列表，课程页成绩子视图下底栏下滑可打开考试列表。点击右上角更多不加振、不走跟手。
- 手势过程中不显示上滑/下滑引导提示。

### 点击抑制

有效拖动或 Sheet 跟手后约 450ms 内抑制 click（勿用 microtask 立刻解除）。遮罩关闭须避开 Sheet `isActive`。不得删除该保护。
主页面横滑完成切页后，Android WebView 可能不生成下一次轻点的 `click`；手势路由须在该次轻点的 `pointerup` 直接激活命中的按钮或链接，并抑制浏览器可能随后补发的 click，人员与课程页不得要求点击第二次。
Sheet 手势关闭进入落位动画时，浮层须立即退出命中并解除外壳 `inert`，但继续完成视觉动画；同一指针序列随后补发或重定向到下层的 click 仍须被抑制。下一次真实 `pointerdown` 须立即完成残余关闭状态并解除旧保护；若命中按钮/链接等控件，手势路由在 `pointerup` 直接激活一次，再抑制浏览器可能补发的 click，禁止依赖 Chromium / Android WebView 是否合成 click。
全屏设置页/学生名单的手势关闭遵循同规则：关闭落位开始后面板立即退出命中、遮罩与面板同步收尾；关闭后下一次 `pointerdown` 命中控件时，即使该触点被全屏拖拽路由认领（claim blocked），也须在 `pointerup` 直接激活一次并抑制随后可能补发的 click。
Sheet 手势认领了指针时：未发生列表滚动/面板跟手的短触，由手势路由在 `pointerup` 上直接激活命中的按钮等控件，并抑制浏览器可能补发的 click；不以 WebView 是否合成 click 为准。列表滚动或面板跟手开始后才 `setPointerCapture`。
IME 浮层的取消/保存/删除走 `src/scripts/pointer-guards.js` 的立即操作与幽灵点击保护（作业、考试、人员、课程、高亮科目共用）；课程 Sheet 另以 `#app.is-course-sheet-ghost-guard` 短暂关闭下层命中，避免课表格 `:active` 闪动。切后台、旋转或系统返回前须先 `cancelActivePointerGesture` 结束当前指针序列并清残余保护。

## 8. 触觉反馈

所有触觉统一为 `10ms`，由 `src/scripts/haptics.js` 的 `Haptic.light` / `Haptic.medium`（同为 `10`）与 `haptic()` 提供；业务代码禁止直接写 `navigator.vibrate` 毫秒数。不可用或抛错时静默降级。

| 场景 | 调用 |
| --- | --- |
| 底栏按钮、底栏越段、分段控件越段、完成切换、字母索引切换字母、上滑打开“更多”Sheet | `haptic(Haptic.light)` |
| 长按打开打分、保存分数成功、确认面板「确认」 | `haptic(Haptic.medium)` |

在 Capacitor Android 壳内：只通过 `@capacitor/haptics` 的 `vibrate({ duration: 10 })` 发振，**不得**再调用 `navigator.vibrate`；原生 WebView / 控件默认 haptic 须关闭，避免系统层与 JS 各震一次。纯 Web（LAN / 浏览器）仍只用 `navigator.vibrate(10)`。

不在以下场景振动：设置页开合、点击按钮打开/关闭更多、作业列表开合、Toast、校验失败、取消、内容区滑页过程中的连续振动。

## 9. 设置页

打开方式：

- 点击顶栏左侧“设置”；设置页自左侧滑入并覆盖整个应用，关闭时反向滑出左侧。

关闭方式：

- 点击左上角返回按钮。
- 在设置页内从右往左横滑（手指向左拖）：设置页 1:1 跟手左移，松手后位移达到 `max(180px, 视口宽 40%)`，或以约 `36px+` 行程且约 `0.4px/ms` 速度向左甩动时关闭，否则回弹；`pointercancel` 等中断时回弹。
- 按 Escape 或系统返回键（仅当设置页为当前最上层时）。

内容与状态：

- 顶部只显示返回按钮与居中标题「设置」；内容分为「外观」「名单」「备份」三组。
- 「深浅色切换」显示当前主题并可立即切换；「学生名单」在设置之上打开独立全屏编辑页且不关闭设置；「导入备份」从 JSON 文件恢复业务数据；「导出备份」保存到文件。
- `state.drawerOpen === true`（字段名保留）。
- `.app` 具有 `.drawer-open`。
- 设置页 `aria-hidden="false"`，顶栏设置按钮 `aria-expanded="true"`。
- 打开时焦点静默移到返回按钮且不导致滚动；关闭时焦点静默返回顶栏设置按钮。

学生名单全屏页：

- 从设置「学生名单」进入：设置页保持打开，名单与设置页共用自左侧滑入的全屏动画、同一 60px 顶栏结构与 44px 返回按钮；名单盖在设置之上。
- 返回钮或 Escape（无二级层时）关闭名单后回到仍然打开的设置，并将焦点还给「学生名单」入口；名单页内从右往左横滑时按设置页同一阈值、速度和回弹规则跟手关闭，遮罩与右缘投影同步跟随（规则见「水平拖动」）。
- 列表展示当前名单与人数；支持新增、改名、删除，交互对齐作业/考试列表（改名/新增用顶部名称 Sheet：小字「学生」，改名大字「修改姓名」、新增大字「新增」；字段「姓名」；主按钮「保存」/「添加」；删除经确认面板，标题「删除学生」）。名称 Sheet 另提供「首字母」选择（A～Z 与 `#` 共 27 个按键）：未手动点选前随姓名输入自动推导（以 `name-initial.js` 姓表为准），手动点选后以所选为准并持久化到学生记录；登记页姓名首字母索引按该持久化字段定位与高亮。
- 至少保留 1 人；人数达到座位容量（104）时禁用新增。删除级联清理该生座位、作业记录、课程成绩与班干/值日指派。姓名 trim 后非空且不超过 40 字（仅写入侧强制）。
- Escape / 系统返回：确认 → 学生名称 Sheet → 全屏名单页 → 其余既有栈。
- 全屏页呈现期间不得认领底层登记网格/成绩/底栏的作业或考试打开手势；名单列表纵向滚动仍优先由原生滚动处理（`touch-action: pan-y`），横向左滑交由全屏关闭手势处理。

关闭后反向恢复，并清除拖动产生的行内 transform 和 `.dragging`。

## 10. 更多菜单、设置与 Toast

- 顶栏右侧“更多”或底部上滑打开同一个底部 Sheet；登记视图提供网格/座位切换、新建作业、清除当前作业和姓名字号，座位额外提供编辑模式与座位视图复位；人员和课程页按当前子视图显示对应动作。更多菜单固定提供「打开设置」入口，点击后关闭更多菜单并打开设置页，关闭设置页时焦点回到顶栏“更多”按钮。新建作业关闭更多菜单后直接打开作业名称（新增）Sheet，与作业列表内「新增作业」使用同一套校验与落库。
- 设置与其它业务主浮层互斥，但学生名单及其姓名/确认层可叠在设置页之上；更多菜单与其它业务主浮层互斥。Escape 与 Android 系统返回键共用 `src/scripts/overlay-stack.js` 的关闭栈；`sheet-drag.js` 的 `SHEET_STACK_ORDER` 是其中 Sheet 的有序投影。顺序为：确认面板 → 高亮科目 → 成绩统计 → 考试名称 → 考试列表 → 科目编辑 → 节次改名 → 课表格 → 成绩 → 人员编辑 → 人员选择 → 作业名称 → 作业列表 → 学生姓名 Sheet → 学生名单全屏页 → 学生记录 → 更多菜单 → 姓名字号 Popover → 设置页 → 座位横屏。无浮层可关时，系统返回键退出应用。
- Toast 使用 `role="status"`，显示约 1600ms。
- 新消息到来时替换旧消息并重新计时；不得叠加多个 Toast。

## 11. 可访问性与输入

- 原生交互优先使用 `<button>`，不可用可点击 `<div>` 代替。
- 纯装饰 SVG 使用 `aria-hidden="true"`；无可见文案的按钮必须有 `aria-label`。
- 当前主导航项维护 `aria-current="page"`；更多菜单、设置页和姓名字号维护 `aria-hidden`，更多与设置按钮维护 `aria-expanded`。
- 人员页与课程页分段控件使用 `role="tablist"` / `role="tab"`，并以 `aria-selected` 同步当前子视图。
- 顶栏中间标题在登记页可点（打开作业列表），在课程页成绩子视图可点（打开考试列表）；人员页与课程页课表子视图为禁用态。
- 无可见文字的主导航项必须用 `aria-label` 提供页面名称。
- 键盘可触发所有按钮和字号滑杆；Escape 与系统返回键须能关闭当前最上层浮层或全屏页（见「更多菜单、设置与 Toast」关闭栈）。
- 业务浮层或设置页（含更多菜单、确认、作业、学生记录、人员/课程 Sheet、设置、姓名字号）打开期间，顶栏、主内容视口与底栏设为不可操作（`inert`），避免键盘焦点落到底层壳层控件；多层叠开时仅在全部关闭后解除。
- 不阻止非必要的键盘默认行为。
- 新增定时动效或位移动效时，必须兼容 reduced motion。

## 12. 必测场景

1. 首屏落在“登记 / 网格”，glider 和所有 active 状态一致。
2. 连续左右滑到两端，索引不越界且边缘有阻尼。
3. 慢拖未过阈值回弹；快速甩动切换一页。
4. 页面纵向滚动不误切页。
5. 点击当前底导航两次，子视图来回切换，指示点同步；登记页无需分段控件也可往返网格 / 座位；人员/课程分段轨道内横滑只切子视图。
6. 网格或座位视图从更多菜单打开姓名字号，实时调整时两处姓名同步变化；刷新恢复该值，更多菜单与 Popover 均保持关闭。
7. 网格视图更多菜单可切换至座位视图、新建作业、清除当前作业与姓名字号；座位视图可切换回网格并显示姓名字号、编辑与复位；人员页显示班干/值日操作；课程页显示课表/成绩操作（含高亮科目、新增考试、成绩统计）；姓名字号在人员/课程页不可见。
8. 底栏/登记网格/课程成绩视图上滑可跟手打开“更多”Sheet；打开更多或全屏设置后不能触发背后的页面手势。设置页与学生名单页均可从右往左横滑跟手关闭，并使用相同的位移/甩动阈值与回弹；设置进入学生名单时保持打开，关闭名单后返回设置；各层均按关闭栈响应 Escape 与系统返回。
9. 登记页字母索引：落稳后渐显为居中短滑块；主页面横移立刻渐隐；按住展开更大字母条（快速渐变+侧滑）、高亮匹配学生并轻触反馈；松手后字母条侧滑渐隐收回，徽标与高亮约 400ms 清除；索引手势不触发切页或打开作业/菜单。
10. 课表格区域横滑可切主页面；轻点仍打开编辑。连续触发多条 Toast（如复制未交、保存成功）时只显示最后一条。

# MyWS1 网格与座位功能迁移档案

> 状态：**已完成**。本文只记录迁移背景、关键决策和结果，不参与日常规范优先级。现行约束见 [`../README.md`](../README.md)。原始逐步执行日志可通过 Git 历史回溯。

## 1. 背景

本项目曾参考 MyWS1 的网格与座位能力，将原有静态演示扩展为可操作的本地业务 Demo。迁移只借鉴业务行为，不复制 Vue/TypeScript 技术栈；本项目始终保持原生 HTML、CSS、ES Modules 和零构建 Web 启动。

## 2. 迁移范围

已迁移：

- 46 名学生的完成登记、计分和清除；
- 作业选择、新增、改名、删除与独立统计；
- 网格与座位共享同一份学生、作业、完成和分数状态；
- 13×8、104 个逻辑位置的座位画布；
- 座位移动、交换、平移、缩放、惯性和复位；
- 批量标记、清除、复制未交名单和恢复默认；
- 严格业务持久化、主题、短横屏和软键盘适配。

未迁移：

- Vue、TypeScript、组件框架或构建工具；
- 登录、后端、云同步和真实学校数据；
- 与当前三页双子视图信息架构冲突的页面结构。

## 3. 关键决策

| 决策 | 最终结论 |
| --- | --- |
| 状态边界 | `state.js` 只保存 UI 瞬时状态；`roster-store.js` 是业务状态唯一可写来源。 |
| 双视图同步 | 网格与座位只订阅同一个 Store，不分别维护完成或分数。 |
| 座位模型 | 使用 13×8、104 个逻辑位置；默认映射 46 名学生。 |
| 持久化 | 使用严格 Schema、已知版本迁移和非法数据整体回退。 |
| 主题 | 浅色为基线，深色只覆盖语义 token。 |
| 横屏 | 仅宽至少 500px 且高不超过 500px 时，登记网格改为 10×5。 |
| 手势 | 保留原有主页面、底栏与 Sheet 手势；座位画布拥有自身平移/缩放手势。 |
| 技术栈 | 不引入 MyWS1 的框架和依赖，只迁移可验证行为。 |

## 5. Schema 演进

迁移最初只覆盖学生、座位、作业、完成和作业分数，后续逐步加入人员与课程字段。当前业务对象使用 **Schema Version 4**：

- Version 1：登记与座位基础数据；
- Version 2：加入人员数据；
- Version 3：人员指派的过渡结构；
- Version 4：人员改为 `studentIds` 多选，并纳入完整课程数据。

`roster-storage.js` 支持已知的 1/2/3 → 4 迁移；未知版本或关联失效时整体回退默认值。

## 6. 最终验收结论

迁移收口时已验证：

- 单元测试与 JavaScript 语法检查通过；
- 页面/导航索引、必需 ID 和受控存储键符合契约；
- 网格 46 人、座位 104 个逻辑位置与 46 张座位卡一致；
- 完成、计分、作业、座位、批量和持久化跨视图同步；
- 320px、390px、430px 竖屏与短横屏无关键溢出；
- 主导航、Sheet、Toast、reduced motion 和 Android 预览路径完成回归。

后续功能以现行产品、视觉、交互和工程文档为准，不从本档案恢复过时阶段约束。

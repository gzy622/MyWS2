# 项目术语表

本表从当前产品模型、实现边界和用户可见语言出发独立整理，用于统一需求、设计、开发、测试和提交说明。它不是 DOM 契约副本；发生行为冲突时，以对应现行文档为准。

## 1. 使用规则

- 用户可见名称优先用中文；代码标识保留现有英文。
- 同一概念只选一个主称呼；历史别名仅用于检索旧记录。
- “页面”“视图”“浮层”“状态”和“记录”不可互相替代。
- 讨论数据时区分“作业分数”和“课程成绩”，两者不是同一业务集合。

## 2. 产品与信息架构

| 标准术语 | 定义 | 代码或示例 |
| --- | --- | --- |
| 教师工作台 | 本项目产品名称；面向手机的本地高保真 Demo。 | 应用名「教师工作台」 |
| 主页面 | 底部导航对应的一级页面，共人员、登记、课程 3 个。 | `.page[data-page]` |
| 子视图 | 主页面内部互斥的二级内容，共 6 个。 | `.subview[data-view]` |
| 人员页 | 管理班干与值日的主页面。 | `data-page="0"` |
| 登记页 | 管理作业完成、作业分数、网格与座位的主页面。 | `data-page="1"` |
| 课程页 | 管理周课表与课程成绩的主页面。 | `data-page="2"` |
| 登记页 / 网格视图首屏 | 刷新后的默认画面。 | `currentPage = 1`，各页 `subviews = 0` |

六个子视图的标准名称：**班干视图、值日视图、网格视图、座位视图、课表视图、成绩视图**。

## 3. 领域术语

| 标准术语 | 定义 | 注意 |
| --- | --- | --- |
| 学生 | 名单中的领域实体，以稳定正整数 ID 标识，持久化姓名首字母（`initial`，单个 A～Z 或 `#`）。 | Demo 默认 46 人，不代表真实学生。 |
| 名单 | 学生集合及其默认顺序；不是某个页面的 DOM 列表。 | 属于业务 Store。 |
| 作业 | 登记完成状态和作业分数的归属对象。 | 至少保留 1 个。 |
| 活动作业 | 当前正在查看和操作的作业。 | `activeAssignmentId`；优先于含糊的“当前任务”。 |
| 完成记录 | 学生在某项作业下已完成的领域记录。 | `submissions`；键为 `(assignmentId, studentId)`。 |
| 已交 | 完成记录在界面上的状态文案。 | “已交”是状态表达，“完成记录”是数据名称。 |
| 作业分数 | 学生在某项作业下的分值。 | `scores`；存在分数即视为已交。 |
| 课程成绩 | 学生在某场考试、某个科目下的分值。 | `courseGrades`；键为 `(examId, subjectId, studentId)`；与作业分数完全分立。 |
| 班干项 | 一个班级职位及其指派学生。 | `roles`；可多人指派。 |
| 值日项 | 一个值日标题、任务说明及其指派学生。 | `duties`；可多人指派。 |
| 指派 | 将一个或多个学生关联到班干项或值日项。 | 选人 Sheet 中先改草稿，确认后写 Store；可用「搜索姓名」筛选名单，无结果显示「无匹配学生」。 |
| 节次 | 课表中的固定时间段。 | `periods`，固定 10 项，可改名不可增删。 |
| 课表格 | 某工作日与某节次交叉位置的科目文本。 | `scheduleSlots`。 |
| 科目 | 课程成绩的列定义。 | `subjects`；至少保留 1 个。 |
| 考试 | 课程成绩的场次维度。 | `exams`；至少保留 1 场；默认「考试 1」。 |
| 座位逻辑位置 | 13×8 逻辑网格中的一个位置。 | `seatIndex` 为 `0～103`。 |
| 座位卡 | 某位学生在座位视图中的可见呈现。 | 46 张；不是逻辑位置本身。 |
| 座位映射 | 学生与座位逻辑位置之间的一一关系。 | `seats`。 |

## 4. 界面构件

| 标准术语 | 定义 | 代码映射 |
| --- | --- | --- |
| 应用外壳 | 承载整个手机界面的边界容器。 | `#app.app` |
| 顶栏 | 应用顶部的设置、标题、更多三列区域。 | `.topbar` |
| 内容视口 | 显示并接收主页面手势的可视区域。 | `#viewport` |
| 页面轨道 | 由 3 个主页面组成的横向移动容器。 | `#pages` |
| 分段控件 | 人员页和课程页切换子视图的两项控件。 | `.segments` |
| 底部主导航 | 切换 3 个主页面的底部控件。 | `#nav` |
| 导航滑块 | 跟随当前主页面移动的底栏选中底。 | `#glider` |
| 子视图指示点 | 表达每个主页面当前子视图的小点。 | `.subdots i` |
| 学生网格 | 网格视图中的 5×10（短横屏 10×5）整体网格。 | `#studentGrid` |
| 学生格 | 学生网格中的原生按钮单元。 | `.student-card`；不要因 class 名称称为“学生卡片”。 |
| 姓名字母索引 | 登记页右侧按姓名首字母临时定位和高亮的控件；命中的首字母取自学生持久化字段 `initial`。 | `.letter-index`；名单编辑可手动调整 `initial`。 |
| 座位画布 | 支持平移、缩放和编辑拖放的座位视图工作区。 | `seat-canvas.js` 管理 transform。 |
| 座位横屏模式 | 由用户主动进入的座位查看状态；隐藏顶栏与底部主导航，横向显示姓名并自动适应回中。 | `seatLandscape`；刷新后重置。 |
| 快速打分模式 | 登记页会话态：轻点卡片直接打开打分 Sheet，长按只切换完成；与座位编辑手势互斥但标记可保留；开启时底栏滑块带淡蓝描边。 | `quickScoreMode` / `.nav-glider--quick-score`；刷新后重置；系统返回不退出。 |
| 整十模式 | 打分 Sheet 会话态：Sheet 内「整十」开关；开启后键盘为 `0/10/…/100`，点一次即写入并关 Sheet；登记与课程成绩共用同一开关状态。 | `tensScoreMode` / `.student-score-tens-toggle`；刷新后重置。 |

## 5. 浮层体系

| 标准术语 | 定义 | 示例 |
| --- | --- | --- |
| 浮层 | 覆盖在主界面之上的 UI 总称。 | Sheet、Popover、Toast 均属于浮层。 |
| Sheet | 从顶部或底部进入、可纵向跟手的模态面板。 | 更多菜单、学生记录、作业列表、考试列表。 |
| 底部 Sheet | 自下而上进入的 Sheet。 | 更多菜单、学生记录、确认面板、人员选择、课程成绩、成绩统计。 |
| 顶部 Sheet | 自上而下进入的 Sheet。 | 作业列表、作业名称、考试列表、考试名称、课表格编辑、节次改名、科目编辑、高亮科目、人员编辑。 |
| 更多菜单 | 顶栏更多按钮打开的底部 Sheet；顶部固定提供深浅色切换与打开设置，中部按当前页面和子视图提供操作，底部固定显示对应清除项。 | `#moreMenu`。 |
| 设置页 | 由顶栏设置按钮或「更多」菜单「打开设置」入口打开的独立全屏界面，包含外观、名单、表格数据与 JSON 备份。 | `#menuDrawer`；`drawer` 只作为历史代码字段与 class 前缀保留。 |
| Popover | 依附触发点的轻量非全屏控件。 | 姓名字号。 |
| 确认面板 | 危险或批量操作前的底部 Sheet。 | `.confirm-sheet`。 |
| 遮罩 | 模态浮层背后的半透明阻断层。 | scrim；中文统一写“遮罩”。 |
| Toast | 顶部短暂、非模态的状态反馈。 | `#toast`；不进入 Sheet 关闭栈。 |
| 活动浮层 | `state.activeOverlay` 当前记录的业务浮层。 | 包含 `more`、`roster-editor`；学生名单可叠在设置页之上，其余主浮层与设置互斥。 |
| 最上层 Sheet | 当前关闭、拖动和返回操作首先作用的 Sheet。 | 顺序由 `overlay-stack.js` 定义，`SHEET_STACK_ORDER` 是其 Sheet 投影。 |

标准关闭顺序（高到低）：确认面板 → 高亮科目 → 成绩统计 → 考试名称 → 考试列表 → 科目编辑 → 节次改名 → 课表格 → 课程成绩 → 人员编辑 → 学生选择 → 作业名称 → 作业列表 → 学生姓名 Sheet → 学生名单全屏页 → 学生记录 → 更多菜单 → 姓名字号 Popover → 设置页 → 座位横屏。Toast 不进入关闭栈。

## 6. 状态与交互

| 标准术语 | 定义 |
| --- | --- |
| UI 瞬时状态 | 页面、子视图、浮层、编辑模式、快速打分模式、整十模式、画布 transform 等刷新后重置的状态。 |
| 业务状态 | 学生、座位、作业、完成、分数、人员和课程数据。 |
| Store | 业务状态的唯一可写来源，即 `roster-store.js`。 |
| 草稿 | 浮层内尚未确认的输入或选择；不属于已提交业务状态。 |
| 持久化 | 将允许的数据写入受控 `localStorage` 键，并在刷新后恢复。 |
| 表格数据 | 设置页提供的多工作表 XLSX；包含全部业务 Store 数据，用于查看、修改与导入替换，并可导入 v2/v1 工作簿和旧 CSV。 | `workbook-transfer.js`；按钮「导入表格」「导出表格」。 |
| 六表工作簿 | 版本 3 的 XLSX 交换文件，固定按顺序包含座位表、作业登记、班干安排、值日安排、课程表和考试成绩。 | `WORKBOOK_FORMAT_VERSION = 3`；当前只导出此格式。 |
| v2 五表工作簿 | 版本 2 的历史 XLSX 交换文件，固定包含学生名单、作业登记、人员安排、课程表和考试成绩；只保留导入兼容。 | `V2_WORKBOOK_FORMAT_VERSION = 2`。 |
| 座位表 | v3 工作簿中的 8×13 完整座位矩阵和下方讲台；可见区只显示座位，姓名竖排并适配竖向 A4 单页打印，名单与稳定编号隐藏保存。 | A1:M10 为可见及打印区域。 |
| 成员序列 | 班干/值日工作表中一个单元格内的成员集合；可见内容只显示姓名，以「；」分隔，反斜杠转义分隔符。 | 隐藏编号和显示快照用于稳定恢复；编辑后的重名姓名拒绝导入。 |
| 隐藏交换数据 | 工作表隐藏行列中的格式版本、数据版本、数量、学生编号、实体编号和成员编号序列，用于导入校验与稳定关联。 | 用户不直接编辑；导入时读取。 |
| JSON 备份 | 设置页提供的原样备份格式；导入确认后整库替换业务数据。 | `backup.js`；按钮「导入备份」「导出备份」。 |
| 渲染结果 | class、ARIA、data 属性和 CSS 自定义属性；它们不是第二份状态源。 |
| 跟手 | 面板或页面位移实时对应指针位移的拖动阶段。 |
| 落位 | 指针释放后按阈值决定打开、关闭、切换或回弹。 |
| 轴锁定 | 手势超过阈值后固定为水平或垂直方向，本次手势不再换轴。 |
| 点击抑制 | 有效拖动或长按后短暂阻止伴随 click 的误触保护。 |
| 静默焦点 | 程序化移动焦点但不显示不恰当焦点环的处理。 |
| 受控持久化键 | 工程规范明确允许访问的 `localStorage` 键。 |

## 7. 工程与交付

| 标准术语 | 定义 |
| --- | --- |
| Web 源码 | `src/` 下唯一应手工修改的 HTML、CSS 和浏览器脚本。 |
| 浏览器模块 | `src/scripts/*.js` 中由页面直接或间接加载的 ES Module。 |
| 工具脚本 | `tools/` 下只在开发、同步或交付时运行的 Node/PowerShell 文件。 |
| Pi 子智能体 WebUI | 只在本机运行的只读状态界面，用卡片展示由 Codex 分派的 Luna、DeepSeek Flash 等 Pi 子智能体及其头像、名称、模型、思考等级、任务和已工作时间；不属于教师工作台产品页面。 |
| 生成资源 | `www/` 和 `dist/` 下可由工具重建的文件。 |
| 零构建启动 | 直接运行 `node lan-server.js`，无需先转换 `src/`。 |
| 内容指纹 | 对全部 Web 源码计算 SHA-256 后，将开头 50 位编码为 10 个 Crockford Base32 字符，并按 `XXXX-XXXX-XX` 分组的摘要。 |
| Live Reload | LAN 服务通过 SSE 通知已连接 WebView 刷新的开发机制。 |
| 原生壳 | Capacitor Android 容器；不改变 Web 业务架构。 |
| 业务 Schema | `teacher-workbench.roster.v1` 中数据对象的结构版本；当前为 4。 |
| 整体回退 | 持久化数据任一关键约束失效时放弃整份数据并使用默认值。 |

## 8. 不推荐用语

| 避免使用 | 改用 | 原因 |
| --- | --- | --- |
| 安排页 | 人员页 | 当前一级导航名称是“人员”。 |
| 抽屉（用户界面名称） | 设置页 | `drawer` 只是保留的内部字段/class 名。 |
| 学生卡片（指网格） | 学生格 | 网格是统一分隔线结构，不是独立卡片列表。 |
| 当前任务 | 活动作业 | 避免与值日任务、课表操作混淆。 |
| 分数（无上下文） | 作业分数 / 课程成绩 | 两套数据独立。 |
| 座位（指 DOM 卡片） | 座位逻辑位置 / 座位卡 | 区分位置和学生呈现。 |
| 弹窗 | Sheet / Popover / 确认面板 | 不同浮层有不同状态与手势契约。 |
| 打包目录源码 | 生成资源 | `www/`、`dist/` 不应作为修改来源。 |

## 9. 受控名称速查

- 页面顺序：人员 `0` → 登记 `1` → 课程 `2`。
- 子视图顺序：班干/值日、网格/座位、课表/成绩。
- 默认画面：登记页 / 网格视图首屏。
- 允许持久化：姓名字号、业务 Schema、主题、高亮科目。
- 生成目录：`www/`、`dist/`。
- 源码目录：`src/`。

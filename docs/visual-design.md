# 视觉设计

## 1. 设计方向

关键词：**克制、清晰、轻量、秩序、可信赖**。

界面采用受 OriginOS 6 系统应用启发的冷灰画布、纯白分组卡片和黑色高权重标题；蓝色表达定位、焦点与非危险选中，红色表达完成、危险、错误与关键提交。视觉重点来自字号层级、留白和少量语义色，不依赖大量装饰。

规则：

- 一屏内主要强调色最多 2 种；红色用于完成、危险、错误与关键提交，蓝色用于导航定位、焦点与非危险选中，绿和琥珀只作局部功能语义。
- 红底主按钮使用 `--accent` + `--on-accent`；白底或灰底上的红字、红图标使用 `--accent-text`，二者不得混用。
- 新增作业、考试、学生等非危险主操作使用 `--action-primary` + `--action-primary-text` 的低饱和雾蓝组合；它与蓝色定位语义同源，但不得使用高饱和蓝色大底。
- 正文不得使用低对比浅灰；白字只放在足够深的背景上；主按钮与正文级强调色对比度目标约 4.5:1。
- 不新增彩虹渐变、霓虹色或高饱和蓝紫大底；纯黑只用于文字和深色主题控件。
- 渐变只可用于现有底部导航背景的轻微遮罩，不作为卡片主视觉。
- 浅色是默认基线；深色模式只覆盖语义 token，完成、计分、危险操作和正文必须保持可辨识对比度。

## 3. 字体层级

- 不在项目中嵌入 vivo Sans 字体文件；字体栈使用 `"vivo Sans", "Noto Sans CJK SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`，设备存在 vivo Sans 时优先使用，否则自然回退。
- 页面 `h1`：31～38px、粗体、紧凑字距，是页面唯一最大标题。
- Hero 数值/主文案：32px、粗体；不得再增加更大的竞争标题。
- 区块标题：14px、粗体；正文：12～14px；辅助标签：10～12px。
- 每张卡片最多 3 个清晰文本层级。
- 禁止大段全大写英文、花体、超宽字距和无意义的超粗字体。

## 4. 布局与间距

- `.app`：宽度上限 430px，高度上限 920px；桌面宽屏仍显示单个手机容器。
- 常规内容水平边距：20px；登记网格为最大化可视面积使用 12px。
- 顶栏基础高度：60px；底部导航基础高度 76px，并计入安全区。
- 顶栏后的额外内容间距保持紧凑：常规页面 10px，登记网格 6px；释放的空间归还给主内容区。
- 主要区块间距通常 18～24px；卡片内部间距 16～20px；紧密元素间距 3～12px。
- 必须使用 `env(safe-area-inset-top/bottom)`，不得让刘海或 Home Indicator 遮挡控件。
- 系统输入法弹起时，整壳高度与顶栏/底栏不得被 Visual Viewport 压矮；仅当前文本输入所在浮层使用 `--ime-inset-bottom` 让出键盘区域。
- 页面内容变多时让当前 `.page` 纵向滚动，不让 `body` 或整个 `.app` 滚动。
- 默认禁止文本选中与长按呼出菜单；仅 `input`、`textarea` 与 `contenteditable` 允许选中文本。
- 视口使用 `user-scalable=no` 为既定触控约定；页面内禁止双指缩放。字号放大依赖操作系统或 Android 壳的系统字体设置，不在 Web 层提供双指缩放放大。

## 5. 形状、边框与阴影

- 圆角按层级使用：手机容器 30px（桌面预览）、Hero 与普通卡片 16px、底导航 20px、小控件 12～18px；搜索和分段控件可使用完整胶囊。
- 普通卡片优先依靠纯白底与画布形成层级，可使用发丝描边或极弱阴影，不同时强化两者。
- Hero 与普通卡片保持同一白色表面，只通过排版和短色条区分语义。
- 不把每段文字都套卡片；卡片只表达一个可识别的信息组。
- 不新增厚边框、强发光、拟物纹理或过量 `backdrop-filter`。
- 全屏设置页与学生名单共用遮罩与边缘投影：遮罩使用 `--scrim` 语义色，透明度与面板位移 1:1 跟手，落位与面板同时长同缓动（`--duration-sheet` / `--ease`）收尾，遮罩完全消失即面板完全移出；面板右缘投影使用 `--shadow-sheet-right`，随面板移动且只在面板可见时绘制，退出动画期间随面板一起滑出。退出落位时面板额外移出右缘投影范围（`--shadow-sheet-right-clearance`），确保切换为隐藏前阴影已完全离开视口，禁止末帧跳变。遮罩 `pointer-events: none`，不拦截下层点击。

## 6. 组件规则

### 顶栏

- 三列布局使用左右各 44px 固定操作列与中间 `minmax(0, 1fr)` 标题列；设置使用 24px 双轨双空心圆调节滑杆，更多使用竖排双空心圆点。标题始终单行几何居中，字号随窄屏在 18～21px 内收敛；超长名称在中间列内省略，不换行、不增高顶栏、不侵入左右操作列，完整名称继续由控件 `aria-label` 表达。登记页作业标题与成绩页考试标题右侧保留向下小箭头，文字左侧使用同宽占位，省略时箭头仍须完整可见。
- 设置与更多按钮保持至少 44×44px 触控区，图标在触控区内居中并保留准确的 `aria-label` 与 `aria-expanded`；默认无底框，按下或对应界面打开时使用定位蓝色反馈。
- 使用冷灰半透明背景与模糊，不做明显底边或高耸阴影。

### 分段控件

- 人员页与课程页各保留 2 项等宽分段控件。
- 登记页为扩大网格面积不显示分段控件，子视图状态由底部指示点表达。
- 未选中项透明、次要文字色；选中项黑色文字。白色选中底与极弱阴影由 `.segment-glider` 承载，并随子视图以 `transform` 过渡（约 250ms、`--ease`），比底栏 glider 更快以匹配轻反馈。
- 不改造成下拉框、胶囊标签云或水平滚动栏。

### Hero 卡片

- 每个子视图最多 1 张；人员页使用单层内容卡列表（班干/值日），课程页使用单层内容卡表达课表矩阵与成绩表，不使用 Hero。
- Hero 使用紧凑白色信息卡，不使用大面积彩色底、短色条或装饰性进度条。
- 不添加装饰圆环、插画或大面积彩色底；不得用虚构进度百分比或「页面占位」充当主数值。

### 底部导航

- 固定 3 等分，保留项目自身的圆角轨道和随当前页移动的三段式 glider。
- 显示线性图标、页面文字与轻量子视图指示点；可见文字必须与 `aria-label` 一致。
- 激活项使用 `--accent-text`，未激活项使用 `--muted`。
- 基础高度保持 76px，触控目标不得因压缩而失去可用性。
- 快速打分模式开启且落在登记页、非座位编辑时，导航滑块增加淡蓝描边（`.nav-glider--quick-score`，约 `1.5px`、`color-mix` 约 38% `--teal`），用 `box-shadow` 叠加以免影响布局；进入/退出编辑或切离登记页时去掉描边。

### 登记网格

- 网格竖屏基线为 5 列 × 10 行，使用一个大矩形外框和统一分隔线，不把每名学生做成独立卡片；仅在视口宽至少 500px 且高不超过 500px 时切换为 10 列 × 5 行。超过基线格数时须按当前列数增加显式行数（竖屏 `ceil(N/5)`、短横屏 `ceil(N/10)`），背景分隔线同步使用相同行数，不得让额外学生进入隐式轨道或被外框裁剪。外框：`--radius-card` 圆角、`border: 0`、边缘轻阴影 `0 2px 8px rgba(0, 0, 0, .08)`（与分段选中项、座位卡一致）；内部分隔线使用 `--line` 发丝线（`.5px`），须在白底上可清晰辨认。
- 默认 46 名学生按格排列，末尾 4 格留空；首屏完整可见，不依赖业务纵向滚动。
- 学生格为原生按钮。姓名字号默认 16px，可在 14～18px 调节；按下时底色变为 `--control`（与菜单项按下反馈一致）。语义为「未交高亮、已交降权」：未交保持白底与 `--ink-soft` 姓名（字重 500），无角标；已交为极浅灰底 `color-mix(in srgb, var(--paper) 40%, var(--card))`（浅于画布 `--paper`，避免挖空感）、`--muted` 姓名（字重 600），未计分显示灰色微型勾选（`--disabled`），有分数时分数角标同为 `--muted`。座位已交格使用同一浅灰底与加粗姓名，保留发丝分隔线且不增加投影。
- 全屏设置页、学生记录、作业列表与考试列表覆盖在内容之上，不挤占网格面积；学生记录与作业/考试列表沿用 Sheet 卡片表面与对应阴影。
- 不给每名学生加独立描边卡片（仍用整格网格与统一分隔线）；已交格须补齐分隔线，避免相邻激活时接缝消失或加粗。座位卡与学生格使用相同的完成、计分颜色语义。
- 座位卡姓名默认从上到下单列排列，每个汉字单独占一行并在座位格内几何居中，保持正立，不旋转字形，也不得由浏览器自动折成两列；用户主动进入座位横屏模式后改为横向单行排列；横屏下每个可见逻辑行须去除其首张座位卡之前的外围空白单元格，组内过道仍保留；完成勾选与分数角标仍保持横排；查看模式为顶部状态预留稳定空间，姓名统一轻微下移，勾选约 `15px`、分数约 `13px`，分数使用极淡卡片色弱底，兼顾可读性并避开姓名区域。查看模式不使用逐卡圆角、间距和阴影：同组相邻座位无缝组成统一方格网格，以发丝线分隔，仅组间过道保留空隙；按当前占用情况压缩外围空列，同时保留过道与相对位置。默认适配须优先保证座位格宽度约 44px 的可触控尺寸；座位姓名与登记网格共享 `14～18px` 姓名字号控制，默认值在默认画布缩放下约为 16px，调整后仍随画布缩放。编辑模式同步使用方格座位，仅拖动中的座位临时浮起。两种模式均提供「适应」按钮；查看模式另在右下角并列提供「适应」与「全屏」入口，系统方向确认横屏后顶栏与底部主导航隐藏，入口改为「退出全屏」；编辑模式顶部持续显示在座位视口水平居中的轻量状态条：宽度不超过 360px、窄屏两侧至少留 12px，使用弱卡片表面、发丝边框、轻阴影与低饱和青色状态点；动态提示单行省略。右侧「退出」是模式切换而非危险操作，使用 `--action-primary` / `--action-primary-text` 淡蓝语义，不使用红色 `--accent`，并保持至少 44px 触控高度。
- 姓名首字母索引在网格与座位视图均默认呈右侧纵向居中的短滑块（约 6×44px 胶囊拇指、触控命中约 32×52px 并向左扩透明热区），贴靠屏幕右侧；登记网格整体宽度较内容区左右各收 1px（合计窄 2px），为索引留出细缝。任一触摸立即触发完整字母条，按住或纵向拖动可继续切换字母；轻点松手后完整字母条仍保留约 `400ms`，避免只在长按期间可见。字母条约 10px 字、左右对称使字母水平居中、弱卡片底与极弱阴影。指示条与字母条的出现/消失均使用约 `--duration-letter-rail`（120ms）的快速渐变 + 自右侧侧滑（`translateX`，不用缩放）。有匹配用 `--muted-soft`、无匹配用更淡的 `--disabled`；当前字母用 `--teal`。命中学生格/座位卡沿用课表高亮科目同款淡蓝弱强调（`color-mix` 约 10% `--teal` 洗底 + 细 inset 描边），不得使用高饱和大块色或红色弱底，且须保留已交分隔线与分数角标语义。按住时居中偏上显示大号字母徽标（半透明深底 + `--on-accent` 字，约 80px），松手后徽标可再短暂保留。索引默认透明不可点；登记页落稳后 opacity 渐入约 `--duration-fade`，主页面一旦横移则以约 `60ms` 立刻渐隐（进出不对称）。

### 课程表矩阵

- “今天”只表达时间定位，不使用红色警告语义：星期标题保持正文色并用 `--teal` 小圆点标记，整列空格与已排课程仅叠加约 4%～5% 的冷蓝灰洗底，不使用整块 `--accent-soft`。
- 用户配置的高亮科目使用更明显的淡蓝洗底与细描边；当高亮科目位于今天列时仍由高亮科目状态主导，课程格自身的科目标记保持不变。

### 浮层四型视觉语言

浮层按类型对齐；同型内部圆角、阴影、标题与关闭钮一致，异型允许差异。Sheet 遮罩统一引用 `--scrim`；叠在既有遮罩之上的二级浮层改用 `--scrim-stacked`，使叠加结果接近单层深度，禁止整屏亮度骤跳。全屏设置与名单页不使用遮罩。

**共享 Sheet 规则**

- 面板圆角 `--radius-sheet`（26px）；标题 `h2` 24px；关闭钮 38×38 圆形、`--control` 底（`.sheet-close`）。
- 表单字段、操作按钮、提示文案与列表分组优先复用 `sheets.css` 共享规则（`.sheet-field` / `.sheet-btn*` / `.sheet-hint` / `.sheet-list-*`）；圆角控件用 `--radius-control`，分组列表用 `--radius-card`。主按钮 `--accent`+`--on-accent`，次按钮 `--control`，危险操作 `--accent-text`；禁用统一降透明并改 `--muted`。触控主操作不小于 44px（列表行内 36px 图标钮除外）。
- 遮罩淡入 `--duration-fade`，面板滑入 `--duration-sheet` + `--ease`；面板与遮罩动画分离，关闭完成后再隐藏。
- 遮罩不透明度在跟手、归位、常态三段之间切换时必须连续：进入跟手态前先写入当前进度，禁止出现回落到 `.show` 常态（不透明度 1）的中间帧。
- 内容可滚时默认隐藏系统滚动条。作业列表、考试列表、人员选择名单与人员编辑面板等溢出列表使用 `.scroll-thin`：系统条隐藏，右侧以挂在 Sheet 面板上的半透明胶囊滑块指示位置（随面板 `transform` 一起跟手，不用 viewport `fixed`）；滑块用 `opacity` 淡入淡出（停滑约 1.1s 后消失；Sheet 完全关闭时立即收起；桌面悬停可常显）。页面主滚动等其它端口仍保持完全隐藏；成绩表在对应方向溢出时显示同色、同显隐节奏的横向与纵向胶囊滑块，滑动停止约 1.1s 后淡出，桌面悬停时常显。
- 学生记录展示当前学生、大号分数、内置数字键盘、输入错误和取消/保存，以及与其它 Sheet 一致的右上角关闭钮；关闭钮和取消均只关闭 Sheet。错误信息清晰可见且不以颜色作为唯一提示。课程成绩计分 Sheet 复用同一套分数区、键盘与操作按钮版式，并保留自身的清除/保存和右上角关闭入口；标题小字为「考试名 · 科目名」、状态行区分已计分/未计分。成绩表冻结首行与姓名首列（sticky + 实底 + 右缘发丝线）；当前考试由顶栏标题表达，切换与管理走顶部考试列表 Sheet。成绩统计 Sheet 按科目列出平均/最高/最低/已录人数，数字使用 tabular-nums。座位横屏模式下，计分 Sheet 保持底部 Sheet 语义并使用紧凑双栏：标题横跨顶部，状态与分数置于左侧，数字键盘从状态行高度开始置于右侧，操作按钮位于键盘下方；面板限制宽高，横屏外壳按 Visual Viewport 的可见高度与顶部偏移定位，并在 `env()` 未返回有效安全区时仍为系统栏保留最小上下空间；约 360px 的短横屏内须完整显示且不依赖滚动，竖屏布局不变。

**1. 底部 Sheet**（更多菜单、学生记录、确认面板、人员选择、课程成绩/统计）

- 自下而上滑入；阴影 `--shadow-sheet-up`；左右约 12px 边距；人员业务 Sheet 复用同一套圆角、关闭钮与标题层级，不另起视觉体系。
- 更多菜单按当前页面与子视图显示上下文动作，使用小字「当前任务」、标题「更多操作」、顶部把手和右上角关闭钮；动作置于 `--paper` 分组表面，危险动作只用 `--accent-text` 标记语义；「其他操作」分组固定提供「打开设置」入口。
- 学生记录保留 36×4px 把手并在右上角使用共享 `.sheet-close` 关闭钮，确认面板无把手；人员 Sheet 按现有实现保留或省略把手，但其现有关闭钮与标题层级须一致。
- 学生名单全屏页自带顶栏（返回 + 标题 + 人数）与底部「新增学生」；列表置于 `--card` 分组表面并以细线分隔，行内改名/删除图标钮对齐作业列表操作钮；名称二级层复用作业名称 Sheet 字段与主次按钮。

**2. 顶部 Sheet**（作业列表、作业名称、考试列表、考试名称、课表格编辑、节次改名、科目编辑、高亮科目、人员编辑）

- 自上而下滑入；阴影 `--shadow-sheet-down`；圆角同为 `--radius-sheet`。
- 面板底边保留 36×4px 把手（与底部 Sheet 同款）；把手可上拉关闭，阈值为 88px。
- 课表格编辑、节次改名、科目编辑、高亮科目与人员编辑输入 Sheet：自上而下进入，使用 `--shadow-sheet-down`，把手位于面板底边，上滑关闭；顶部安全区、圆角、标题与表单控件继续复用共享 Sheet 规则。
- 作业列表与考试列表 `max-height: calc(100% * 2 / 3)`；列表区单独滚动，溢出时使用滑动显隐的细滚动条（不预留 `scrollbar-gutter`）；「新增作业」/「新增考试」固定在列表下方、把手上方可见。
- 条目置于 `--paper` 分组表面并以细线分隔；作业名称叠于作业列表之上、考试名称叠于考试列表之上（更高 z-index），为二级层，不另占 `activeOverlay`。

**3. 全屏设置与名单页**

- 设置由顶栏左侧按钮打开，自左侧进入并覆盖顶栏、内容区和底部主导航，关闭时反向滑出；顶部使用返回按钮、居中「设置」标题和右侧等宽空位，不使用遮罩、把手或 Sheet 圆角。内容按「外观」「名单」「备份」分组，右下角显示弱化的内容指纹和生成时间。
- 学生名单由设置页打开，与设置页共用自左侧进入/退出的全屏动画、顶栏结构和返回按钮；设置页保持打开并留在其下方，不重新播放关闭或打开动画。
- 名单页自带返回按钮、居中标题、人数、名单列表和底部「新增学生」。关闭后返回仍处于打开状态的设置页，并将焦点还给「学生名单」入口。

**4. 轻量 Popover**（姓名字号）

- 圆角 `--radius-popover`（18px）；弱阴影与短时缩放淡入；不抢 Sheet 视觉权重。

同一时间只显示一个业务主浮层或全屏页（作业名称视为作业列表内的二级层；考试名称视为考试列表内的二级层）。学生名单可叠在设置页之上；除此之外，设置、更多菜单与其它业务主浮层互斥。座位画布空位、讲台和编辑目标保持克制，不引入新主题色。

### 图标

- 主导航和顶栏继续使用线性 SVG，线宽、尺寸一致。
- 功能图标可使用单个汉字作为当前占位方案。
- 不引入 emoji 作为正式图标，不混用多套图标风格。

## 7. 动效

- 标准缓动：`--ease: cubic-bezier(.2, 0, 0, 1)`。
- 页面/导航切换约 420ms；子视图入场约 350ms；轻反馈约 250ms。
- 底部/顶部 Sheet 使用约 300ms 直接滑入/滑出；设置与学生名单均自左侧进入并向左退出（同一时长约 300ms），遮罩约 240ms 淡入/淡出；不使用弹簧或过冲。
- Sheet 本体不参与遮罩的透明度渐变，只做位移；遮罩与面板层分离。关闭动画完成后隐藏面板，禁止阴影回溢到底栏。关闭落位开始后视觉动画可继续，但浮层须立即退出命中，避免透明尾帧拦截下一次触点。
- 面板拖动期间必须取消 transition（严格跟手），松手后恢复；设置页与学生名单横滑跟手使用同一规则，落位由 CSS transition 从松手位置继续。面板与遮罩仅在打开、跟手和落位期间临时提升为合成层，动画完成后立即释放，禁止为全部隐藏 Sheet 长期保留 `will-change`。
- 遮罩跟手期保留 `--duration-scrim-track`（90ms）线性过渡，用于吸收接管动画时的不连续值，避免闪烁跳变；该时长不得增大到可察觉的迟滞。
- 跟手帧只改 Sheet 面板 `transform` 与遮罩元素自身的 `opacity`；禁止在 `.app` / overlay 上用 `--sheet-reveal-progress` 等继承型自定义属性驱动遮罩，以免每帧失效整棵子树。跟手/落位期间 `#app` 可临时加上 `is-sheet-gesturing` 或 `is-page-gesturing` 以关闭顶栏 `backdrop-filter`。主页横滑跟手帧按动画帧合并写入 `#pages` / 底栏滑块 `transform`，并避免每 pointermove 重复切换 dragging / 字母索引可见性。
- 动效只解释状态变化，不添加循环浮动、弹跳或粒子特效。
- 必须保留 `prefers-reduced-motion` 降级。

## 8. 禁止的“廉价审美”模式

- 擅自改成蓝紫渐变 SaaS 风格或恢复与 token 不一致的暖米色主题。
- 到处使用胶囊、玻璃拟态、发光边框和超大阴影。
- 一个页面堆叠许多同质卡片，没有主次。
- 使用 emoji、随机彩色图标或不一致的 SVG。
- 为填满空间而添加无业务意义的统计、头像、图表。
- 同类组件出现不同圆角、间距、字号和颜色。

新增视觉样式前，先证明现有 token 和组件变体无法表达需求；否则必须复用现有系统。

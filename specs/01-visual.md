# 01 · 视觉 Spec

## 1. 设计方向

关键词：**克制、清晰、轻量、秩序、可信赖**。

界面采用受 OriginOS 6 系统应用启发的冷灰画布、纯白分组卡片、黑色高权重标题与红色状态强调。视觉重点来自字号层级、留白和少量高对比色，不依赖大量装饰。

## 2. 唯一颜色基线

颜色必须优先引用 `styles/tokens.css`，禁止在不同组件中创建“几乎相同”的颜色。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#000000` | 主文字、标题与主要图标 |
| `--muted` | `#7a7a7a` | 次要文字、非激活控件 |
| `--paper` | `#f2f2f4` | 应用冷灰背景 |
| `--card` | `#ffffff` | 分组卡片、抽屉与浮层背景 |
| `--control` | `#e9e9eb` | 搜索、分段轨道和次级控件背景 |
| `--line` | `#e6e6e6` | 发丝分割线、网格线 |
| `--accent` | `#f85854` | 完成、当前项、主要操作强调色 |
| `--accent-soft` | `#fde9e8` | 完成态与红色控件弱底 |
| `--teal` | `#0c74fc` | 焦点与局部功能蓝色（保留旧变量名以维持契约） |
| `--paper`（深色） | `#111214` | 深色应用背景，仅在根主题属性覆盖。 |
| `--card`（深色） | `#1c1d20` | 深色卡片与抽屉背景。 |
| `--ink`（深色） | `#ffffff` | 深色主题主文字。 |
| `--muted`（深色） | `#aaaaaa` | 深色主题次要文字。 |
| `--line`（深色） | `#303136` | 深色主题分隔线与描边。 |
| `--accent`（深色） | `#ff6b66` | 深色主题红色强调。 |
| `--accent-soft`（深色） | `#402423` | 深色主题红色弱底。 |
| `--teal`（深色） | `#6aa6ff` | 深色主题焦点蓝色。 |

规则：

- 一屏内主要强调色最多 2 种；红色用于全局状态，蓝、绿和琥珀只作局部功能语义。
- 正文不得使用低对比浅灰；白字只放在足够深的背景上。
- 不新增彩虹渐变、霓虹色或高饱和蓝紫大底；纯黑只用于文字和深色主题控件。
- 渐变只可用于现有底部导航背景的轻微遮罩，不作为卡片主视觉。
- 浅色是默认基线；深色模式只覆盖语义 token，完成、计分、危险操作和正文必须保持可辨识对比度。

## 3. 字体层级

- 不在项目中嵌入 vivo Sans 字体文件；字体栈使用 `"vivo Sans", "Noto Sans CJK SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`，设备存在 vivo Sans 时优先使用，否则自然回退。
- 页面 `h1`：31～38px、粗体、紧凑字距，是页面唯一最大标题。
- Hero 数值/主文案：32px、粗体；不得再增加更大的竞争标题。
- 区块标题：14px、粗体；正文：12～14px；辅助标签：10～12px。
- 每张卡片最多 3 个清晰文本层级。
- 禁止大段全大写英文、花体、超宽字距和无意义的超粗字体。

## 4. 布局与间距

- `.app`：宽度上限 430px，高度上限 920px；桌面宽屏仍显示单个手机容器。
- 常规内容水平边距：20px；登记网格为最大化可视面积使用 12px。
- 顶栏基础高度：60px；底部导航基础高度 76px，并计入安全区。
- 顶栏后的额外内容间距保持紧凑：常规页面 10px，登记网格 6px；释放的空间归还给主内容区。
- 主要区块间距通常 18～24px；卡片内部间距 16～20px；紧密元素间距 3～12px。
- 必须使用 `env(safe-area-inset-top/bottom)`，不得让刘海或 Home Indicator 遮挡控件。
- 页面内容变多时让当前 `.page` 纵向滚动，不让 `body` 或整个 `.app` 滚动。

## 5. 形状、边框与阴影

- 圆角按层级使用：手机容器 30px（桌面预览）、Hero 与普通卡片 16px、底导航 20px、小控件 12～18px；搜索和分段控件可使用完整胶囊。
- 普通卡片优先依靠纯白底与画布形成层级，可使用发丝描边或极弱阴影，不同时强化两者。
- Hero 与普通卡片保持同一白色表面，只通过排版和短色条区分语义。
- 不把每段文字都套卡片；卡片只表达一个可识别的信息组。
- 不新增厚边框、强发光、拟物纹理或过量 `backdrop-filter`。

## 6. 组件规则

### 顶栏

- 三列布局，标题始终几何居中，并随主页面显示“人员”“登记”或“课程”。
- 操作按钮保持至少 44×44px 触控区；左侧菜单图标贴近左侧内容边缘，右侧更多图标等距贴近右侧内容边缘。更多按钮使用与 OriginOS 参考一致、且与菜单图标线宽协调的纵向双空心点，并保留准确的 `aria-label`。
- 使用冷灰半透明背景与模糊，不做明显底边或高耸阴影。

### 分段控件

- 人员页与课程页各保留 2 项等宽分段控件。
- 登记页为扩大网格面积不显示分段控件，子视图状态由底部指示点表达。
- 未选中项透明，选中项为白色底、黑色文字和极弱阴影。
- 不改造成下拉框、胶囊标签云或水平滚动栏。

### Hero 卡片

- 每个子视图最多 1 张。
- Hero 使用紧凑白色信息卡，不使用大面积彩色底、短色条或装饰性进度条。
- 不添加装饰圆环、插画或大面积彩色底。

### 底部导航

- 固定 3 等分，保留项目自身的圆角轨道和随当前页移动的三段式 glider。
- 显示线性图标、页面文字与轻量子视图指示点；可见文字必须与 `aria-label` 一致。
- 激活项使用 `--accent`，未激活项使用 `--muted`。
- 基础高度保持 76px，触控目标不得因压缩而失去可用性。

### 登记网格

- 网格竖屏基线为 5 列 × 10 行，使用一个大矩形外框和统一分隔线，不把每名学生做成独立卡片；仅在视口宽至少 500px 且高不超过 500px 时切换为 10 列 × 5 行。
- 46 名学生按格排列，末尾 4 格留空；首屏完整可见，不依赖业务纵向滚动。
- 学生格为原生按钮。姓名字号默认 16px，可在 14～18px 调节；完成但未计分显示勾选，单元格有 `data-score` 时分数仅作为无背景、无边框的右上角文字角标显示。
- 更多面板、学生记录面板和作业面板悬浮在内容之上，不挤占网格面积；沿用卡片背景、细边框和低透明阴影。

### 登记浮层

- 学生记录面板展示当前学生、分数显示、内置数字键盘、输入错误和保存/清除操作；错误信息清晰可见且不以颜色作为唯一提示。
- 学生网格使用可连续拼接、清晰但不过量的浅红完成底；仅提交状态使用小型红色勾选，有分数时只显示轻量红色分数角标，且激活格必须补齐统一分隔线，避免相邻激活时接缝消失或加粗。学生记录面板保留学生姓名，使用大号分数显示、内置数字键盘和清晰的主次操作。
- 学生记录与通用菜单使用同一套浮动圆角面板：统一 26px 圆角、36×4px 手势提示条、低透明短扩散阴影、标题层级和分组表面。通用菜单不得展示虚构头像资料或六宫格单字入口。
- 作业、更多与确认面板遵循现有抽屉层级、圆角、描边与低透明阴影；同一时间只显示一个业务浮层。
- 座位卡与学生格使用相同的完成、计分颜色语义；座位画布空位、讲台和编辑目标保持克制，不引入新主题色。

### 图标

- 主导航和顶栏继续使用线性 SVG，线宽、尺寸一致。
- 功能图标可使用单个汉字作为当前占位方案。
- 不引入 emoji 作为正式图标，不混用多套图标风格。

## 7. 动效

- 标准缓动：`--ease: cubic-bezier(.2, 0, 0, 1)`。
- 页面/导航切换约 420ms；子视图入场约 350ms；轻反馈约 250ms。
- 抽屉和业务面板使用约 300ms 的直接底部滑入/滑出；遮罩同步以约 240ms 淡入/淡出，不使用缩放、弹簧或过冲。
- 业务面板本体不参与遮罩的透明度渐变，只做底部位移；遮罩淡入淡出必须与面板层分离。面板阴影保持低透明、短扩散，关闭动画完成后隐藏面板，禁止阴影回溢到底栏。
- 拖动期间必须取消 transition，松手后恢复。
- 动效只解释状态变化，不添加循环浮动、弹跳或粒子特效。
- 必须保留 `prefers-reduced-motion` 降级。

## 8. 禁止的“廉价审美”模式

- 擅自改成蓝紫渐变 SaaS 风格或恢复与 token 不一致的暖米色主题。
- 到处使用胶囊、玻璃拟态、发光边框和超大阴影。
- 一个页面堆叠许多同质卡片，没有主次。
- 使用 emoji、随机彩色图标或不一致的 SVG。
- 为填满空间而添加无业务意义的统计、头像、图表。
- 同类组件出现不同圆角、间距、字号和颜色。

新增视觉样式前，先证明现有 token 和组件变体无法表达需求；否则必须复用现有系统。

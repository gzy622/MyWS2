# 01 · 视觉 Spec

## 1. 设计方向

关键词：**克制、温暖、清晰、轻量、可信赖**。

界面应像精心排版的教师随身工具，而不是炫技型概念稿。视觉重点来自字号层级、留白和少量高对比色，不依赖大量装饰。

## 2. 唯一颜色基线

颜色必须优先引用 `styles/tokens.css`，禁止在不同组件中创建“几乎相同”的颜色。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#17252a` | 主文字、深色选中态、深色卡片 |
| `--muted` | `#748084` | 次要文字、非激活控件 |
| `--paper` | `#f4f1e9` | 应用背景 |
| `--card` | `#fffdf8` | 卡片、抽屉背景 |
| `--line` | `#dedbd1` | 分割线、描边 |
| `--accent` | `#ef6a3a` | 暖橙强调色 |
| `--accent-soft` | `#ffe1d4` | 橙色图标底 |
| `--teal` | `#165b61` | 主功能色、青色卡片 |

规则：

- 一屏内主要强调色最多 2 种；不要让橙、青、深色同时争夺焦点。
- 正文不得使用低对比浅灰；白字只放在足够深的背景上。
- 不新增彩虹渐变、霓虹色、纯黑大底或高饱和蓝紫色。
- 渐变只可用于现有底部导航背景的轻微遮罩，不作为卡片主视觉。

## 3. 字体层级

- 字体栈保持 `Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
- 页面 `h1`：31～38px、粗体、紧凑字距，是页面唯一最大标题。
- Hero 数值/主文案：42px、粗体；不得再增加更大的竞争标题。
- 区块标题：14px、粗体；正文：12～14px；辅助标签：10～12px。
- 每张卡片最多 3 个清晰文本层级。
- 禁止大段全大写英文、花体、超宽字距和无意义的超粗字体。

## 4. 布局与间距

- `.app`：宽度上限 430px，高度上限 920px；桌面宽屏仍显示单个手机容器。
- 内容水平边距：20px。
- 顶栏基础高度：44px；底部保留导航高度 88px，并计入安全区。
- 主要区块间距通常 18～24px；卡片内部间距 16～20px；紧密元素间距 3～12px。
- 必须使用 `env(safe-area-inset-top/bottom)`，不得让刘海或 Home Indicator 遮挡控件。
- 页面内容变多时让当前 `.page` 纵向滚动，不让 `body` 或整个 `.app` 滚动。

## 5. 形状、边框与阴影

- 圆角按层级使用：手机容器 32px（桌面预览）、Hero 25px、底导航 24px、普通卡片 18～20px、小控件 9～15px。
- 普通卡片必须有细描边；阴影低透明、柔和，不制造悬浮玻璃块堆叠。
- Hero 可使用较明显但同色系的阴影。
- 不把每段文字都套卡片；卡片只表达一个可识别的信息组。
- 不新增厚边框、强发光、拟物纹理或过量 `backdrop-filter`。

## 6. 组件规则

### 顶栏

- 三列布局，标题始终几何居中。
- 操作按钮最小高度保持 44px；图标与文案并存。
- 半透明暖色背景和极弱底边，不做高耸阴影。

### 分段控件

- 每页恰好 2 项，等宽。
- 未选中项透明，选中项为 `--ink` 底色配白字。
- 不改造成下拉框、胶囊标签云或水平滚动栏。

### Hero 卡片

- 每个子视图最多 1 张。
- 颜色只从 teal / orange / dark 三种现有变体选择。
- 装饰圆环透明度必须低，不得遮挡文字。

### 底部导航

- 固定 3 等分；深色 glider 只覆盖当前项。
- 图标、文字、子视图指示点都要保留。
- 激活项白色，未激活项使用 `--muted`。

### 图标

- 主导航和顶栏继续使用线性 SVG，线宽、尺寸一致。
- 功能图标可使用单个汉字作为当前占位方案。
- 不引入 emoji 作为正式图标，不混用多套图标风格。

## 7. 动效

- 标准缓动：`--ease: cubic-bezier(.22, .8, .25, 1)`。
- 页面/导航切换约 420ms；子视图入场约 350ms；轻反馈约 250ms。
- 拖动期间必须取消 transition，松手后恢复。
- 动效只解释状态变化，不添加循环浮动、弹跳或粒子特效。
- 必须保留 `prefers-reduced-motion` 降级。

## 8. 禁止的“廉价审美”模式

- 擅自改成蓝紫渐变 SaaS 风格。
- 到处使用胶囊、玻璃拟态、发光边框和超大阴影。
- 一个页面堆叠许多同质卡片，没有主次。
- 使用 emoji、随机彩色图标或不一致的 SVG。
- 为填满空间而添加无业务意义的统计、头像、图表。
- 同类组件出现不同圆角、间距、字号和颜色。

新增视觉样式前，先证明现有 token 和组件变体无法表达需求；否则必须复用现有系统。

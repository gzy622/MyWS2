# 02 · 交互与状态 Spec

## 1. 状态模型

`scripts/state.js` 是唯一状态来源：

```text
currentPage: 0 | 1 | 2
subviews: [0 | 1, 0 | 1, 0 | 1]
suppressNavClick: boolean
drawerOpen: boolean
studentFontSize: 14 | 15 | 16 | 17 | 18
fontSizePopoverOpen: boolean
```

约束：

- `currentPage` 必须经过 `clampPage()`，不可越界。
- 每页独立记住本次会话中的子视图选择。
- 导航、子视图、抽屉和字号浮层状态只存在内存；刷新后回到产品 Spec 定义的初始状态。
- `studentFontSize` 是唯一持久化例外，使用 `teacher-workbench.student-name-font-size` 保存；读取失败或非数值时回退到 `16`，越界数值按 `14～18` 夹取。
- CSS class 和 CSS 自定义属性是状态的渲染结果，不是第二份状态源。

## 2. 主页面导航

用户可通过两种方式切换主页面：

1. 点击底部的另一个导航项，直接进入目标页。
2. 在内容区或底部导航上水平拖动，按距离或速度切换相邻页。

当前导航项被再次点击时，不停留不动，而是切换该页的两个子视图。这是既定功能，不能“修正”掉。

每次渲染必须同步：

- `.pages` 的横向位置。
- `.nav-glider` 的位置。
- 顶栏标题的当前页面名称。
- 导航按钮 `.active` 和 `aria-current="page"`。
- 存在分段控件的页面中，segment 的 `.active`。
- 每页 subview 的 `.active`。
- 每个导航项的子视图指示点 `.on`。

## 3. 子视图

- 点击分段按钮只切换其所属页面的子视图，不切换主页面。
- 安排页和课程页始终恰好 1 个 segment 与 1 个 subview 为 active。
- 登记页不显示 segment，重复点击当前“登记”导航项在网格 / 座位间切换，并由 subview 与指示点表达状态。
- 切换主页面后，该页恢复到本次会话最后选择的子视图。

## 4. 网格字号

- 仅当当前状态为“登记页 / 网格视图”时，点击顶栏“更多”切换姓名字号浮层。
- 其他主页面或登记页 / 座位视图点击“更多”，继续显示“更多功能即将推出”Toast。
- 字号滑杆范围为 `14～18px`、步长 `1px`，拖动和键盘调整时实时更新姓名字号及数值输出。
- 每次有效调整立即写入持久化；刷新后恢复上次字号。
- 点击浮层外部、切换页面 / 子视图或按 `Escape` 时关闭浮层；浮层自身的滑杆手势不得触发横向切页。
- 字号浮层开关不持久化，刷新后始终关闭。

## 5. 水平与垂直手势

轴锁定规则：移动超过 6px 后，以绝对位移较大的方向锁轴，本次手势中不再改变。

### 水平拖动

- 拖动时内容与 glider 必须实时跟手，且不播放 transition。
- 第一页向右、最后一页向左时应用边缘阻尼，不能露出空白页。
- 松手后根据距离或快速甩动决定是否切换；最多切换相邻 1 页。
- 未达到阈值时回弹到当前页。

### 内容区垂直拖动

- 纵向移动当前 `.page` 的 `scrollTop`。
- 不触发横向切页或打开抽屉。
- 浏览器不得在手势中途接管并取消 pointer 序列。

### 底部导航上滑

- 上滑超过提示阈值时显示“继续上滑，打开通用菜单”。
- 上滑超过打开阈值后松手，打开抽屉。
- 提示在结束或取消手势时隐藏。

### 点击抑制

发生有效拖动后，短时间抑制 click，防止松手误触导航按钮。不得删除该保护。

## 6. 抽屉

打开方式：

- 点击左上角“菜单”。
- 从底部导航向上滑过阈值。

关闭方式：

- 点击关闭按钮。
- 点击遮罩。
- 按 `Escape`。
- 下拉抽屉把手超过阈值。

打开后必须同时：

- `state.drawerOpen === true`。
- `.app` 具有 `.drawer-open`。
- 抽屉 `aria-hidden="false"`。
- 焦点移动到关闭按钮且不导致滚动。

关闭后反向恢复，并清除拖动产生的行内 transform 和 `.dragging`。

## 7. Toast

- 非网格状态下的“更多”和抽屉菜单项用 Toast 提供无破坏性的占位反馈。
- Toast 使用 `role="status"`，显示约 1600ms。
- 新消息到来时替换旧消息并重新计时；不得叠加多个 Toast。

## 8. 可访问性与输入

- 原生交互优先使用 `<button>`，不可用可点击 `<div>` 代替。
- 纯装饰 SVG 使用 `aria-hidden="true"`；无可见文案的按钮必须有 `aria-label`。
- 当前主导航项维护 `aria-current="page"`；抽屉和字号浮层维护 `aria-hidden`，“更多”维护 `aria-expanded`。
- 无可见文字的主导航项必须用 `aria-label` 提供页面名称。
- 键盘可触发所有按钮和字号滑杆；抽屉与字号浮层必须支持 Escape。
- 不阻止非必要的键盘默认行为。
- 新增定时动效或位移动效时，必须兼容 reduced motion。

## 9. 必测场景

1. 首屏落在“登记 / 网格”，glider 和所有 active 状态一致。
2. 连续左右滑到两端，索引不越界且边缘有阻尼。
3. 慢拖未过阈值回弹；快速甩动切换一页。
4. 页面纵向滚动不误切页。
5. 点击当前底导航两次，子视图来回切换，指示点同步；登记页无需分段控件也可往返网格 / 座位。
6. 网格视图点击“更多”打开字号浮层，实时调整字号；刷新恢复该值，浮层保持关闭。
7. 离开网格后“更多”恢复占位 Toast，字号浮层不可见。
8. 打开抽屉后不能触发背后的页面手势。
9. 抽屉四种关闭方式均有效。
10. 连续点击多个占位操作，只显示最后一条 Toast。

# 02 · 交互与状态 Spec

## 1. 状态模型

状态分为 UI 瞬时状态与业务 Store 两个边界。`scripts/state.js` 只保存 UI 状态：

```text
currentPage: 0 | 1 | 2
subviews: [0 | 1, 0 | 1, 0 | 1]
suppressNavClick: boolean
drawerOpen: boolean
studentFontSize: 14 | 15 | 16 | 17 | 18
fontSizePopoverOpen: boolean
seatEditing: boolean
activeOverlay: null | 'assignments' | 'student-record' | 'people-pick' | 'people-edit' | 'course-slot' | 'course-period' | 'course-subject' | 'course-grade' | 'course-highlight' | 'more' | 'confirm'
```

`roster-store.js` 是学生、座位、作业、提交、分数、班干、值日、课表与课程成绩的唯一可写来源；网格、座位、人员与课程渲染器只订阅它，禁止双写领域数组。

约束：

- `currentPage` 必须经过 `clampPage()`，不可越界。
- 每页独立记住本次会话中的子视图选择。
- 导航、子视图、通用菜单和姓名字号状态只存在内存；刷新后回到产品 Spec 定义的初始状态。
- `studentFontSize` 使用 `teacher-workbench.student-name-font-size` 保存；读取失败或非数值时回退到 `16`，越界数值按 `14～18` 夹取。业务数据和主题的受控持久化规则见工程 Spec。
- CSS class 和 CSS 自定义属性是状态的渲染结果，不是第二份状态源。

## 2. 主页面导航

用户可通过两种方式切换主页面：

1. 点击底部的另一个导航项，直接进入目标页。
2. 在内容区水平拖动，按内容轮播方向切换相邻页；在底部导航上水平拖动，则直接操控三段式 glider 选择相邻页。

当前导航项被再次点击时，不停留不动，而是切换该页的两个子视图。这是既定功能，不能“修正”掉。

每次渲染必须同步：

- `.pages` 的横向位置。
- `.nav-glider` 的位置。
- 顶栏标题：人员页与课程页显示页面名称，登记页始终显示当前活动作业名称，并在标题文字右侧显示向下小箭头（左侧等宽占位，文字仍居中），提示可点击打开作业列表；从其他页面切回登记时必须立即刷新，不得保留上一页标题。
- 导航按钮 `.active` 和 `aria-current="page"`。
- 存在分段控件的页面中，segment 的 `.active`。
- 每页 subview 的 `.active`。
- 每个导航项的子视图指示点 `.on`。

## 3. 子视图

- 点击分段按钮只切换其所属页面的子视图，不切换主页面。
- 在分段控件轨道内横滑只切换子视图（驱动分段滑块），不切换主页面。
- 人员页和课程页始终恰好 1 个 segment 与 1 个 subview 为 active。
- 登记页不显示 segment，重复点击当前“登记”导航项在网格 / 座位间切换，并由 subview 与指示点表达状态。
- 切换主页面后，该页恢复到本次会话最后选择的子视图。

## 4. 登记业务交互

- 活动作业属于业务 Store。网格和座位卡的轻点只切换当前作业的完成状态；完成与分数按 `(assignmentId, studentId)` 唯一，分数存在即视为完成。
- 长按约 `480ms`、桌面右键打开同一学生记录；移动超过 `9px`、结束、取消或离开均取消长按，成功长按必须抑制同一指针序列的 click。成功长按使用触觉反馈（见「触觉反馈」）。
- 长按打开学生记录即视为打分意图：面板直接显示学生姓名、分数框和内置数字键盘，不再提供二次模式选择或唤起系统软键盘。键盘支持 `0～9`、小数点和退格，只允许形成 `0～100` 且最多一位小数的草稿；保存与清除规则不变。仅提交仍由网格或座位卡轻点完成。学生记录打开后可在除输入框外的全屏区域纵向拖动跟手关闭/回弹，自滚动区域未到边时优先滚动。
- 顶栏登记标题显示活动作业名称，点击打开作业列表（从上往下弹出）；在登记页网格视图下，全屏（顶栏、主内容区、底栏）下滑可打开作业列表、上滑可打开通用菜单；座位视图与其他页面不响应这两类打开手势（底栏上滑打开通用菜单除外）。列表显示已交人数/总人数，支持选择、新增、重命名和删除，至少保留一个作业。删除活动作业后选择相邻可用作业。
- 改名与新增均使用作业名称（二级顶部 Sheet）：标题小字「作业」，改名大字「修改名称」、新增大字「新增」；字段标签「名称」；改名预填当前名称、主按钮为「保存」；新增为空输入、主按钮为「添加」。取消/点遮罩或 Escape 关闭；打开后全屏纵向跟手关闭（输入框上除外），松手按进度/甩动落位；Enter 提交；校验失败以 Toast 提示。删除须经确认面板：标题「删除作业」，确认后以 Toast 提示；禁止使用系统 confirm / prompt。关闭作业列表时须先关闭作业名称。Escape 优先关闭作业名称，再关闭作业列表。
- 作业列表标题为小字「登记」+ 大字「作业」。
- 系统输入法弹起时：顶栏、底栏、页面与其它未聚焦浮层保持布局高度与位置；仅包含当前文本输入的浮层按 Visual Viewport 收缩底部（`--ime-inset-bottom`），不得连带压矮整壳。
- 通用菜单的全部标记、清除、复制未交名单只作用于活动作业；恢复默认须经确认面板（菜单项文案「恢复默认名单」，确认标题「恢复默认数据」，正文须说明将重置名单、座位、班干、值日、课表与科目并清除作业登记/分数与课程成绩）。清除类确认正文须点名活动作业名称。复制未交名单用中文顿号连接，全部已交时不得写入空文本。
- 登记页网格与座位均提供右侧姓名首字母索引条：按姓氏拼音首字母（拉丁名取首字母）匹配学生；按住、轻点或纵向滑过字母时显示大号字母徽标，并以课表「高亮科目」同款淡蓝弱强调命中学生格与座位卡；切换字母时轻触反馈；松手后徽标与高亮约再保留 `400ms` 再清除。无匹配字母可滑过但不点亮学生。字母条手势不得触发主页面切页、作业/通用菜单打开或座位画布平移。
- 字母条默认隐藏；仅主页面**稳定落在登记页之后**才渐变出现（切页 CSS 过渡约 `420ms` 结束后再显示）。主页面一旦出现横向位移（内容区或底栏跟手 / `renderDrag`），字母条立刻快速渐隐并中断进行中的按住高亮；落稳后若仍在登记页再渐显，落在人员/课程则保持隐藏。登记页内网格↔座位切换不因此隐藏字母条。字母条显隐为 UI 瞬时态，不持久化。

## 4.1 人员业务交互

- 班干与值日列表由业务 Store 驱动；每项独立卡片展示。轻点行打开学生选择 Sheet（小字「班干」/「值日」，大字为该项标题），可多选草稿指派；浮层内提示「已选 N 人」或「未选择」；点选条目切换勾选且不关闭 Sheet；「清除」只清空草稿，「确认」才写入 Store 并关闭；关闭/遮罩/Escape 丢弃草稿。列表未指派分别显示「未指定」「未排」，已指派姓名完整换行展示（中文顿号连接）。学生名单列表使用原生纵向滚动（含惯性），Sheet 跟手关闭仅从把手/标题等非列表区域发起。
- 长按约 `480ms` 或桌面右键打开编辑 Sheet（小字「班干」/「值日」，大字为该项标题，说明「删除后不可恢复。」）：班干改职位名，值日改星期标题与任务说明；文案上限 40 字；提供删除，班干与值日各自至少保留 1 项，删除须经确认面板（标题「删除班干」/「删除值日」，不加问号）。输入法弹起时，取消/保存/删除须在 `pointerdown` 立即生效，并短暂吞掉随后的幽灵点击（避免点到确认遮罩/取消而误关）。
- 人员页“更多”：班干子视图显示「新增班干」「清空班干指派」；值日子视图显示「新增值日」「清空值日安排」；主题切换始终可见。新增默认标题为「新班干」「新值日」。清空指派须经确认（标题「清空班干指派」/「清空值日安排」），不清空职位/值日项本身。
- Escape / 系统返回优先关闭确认面板，再关闭人员编辑 Sheet、学生选择 Sheet，再进入既有关闭栈。

## 4.2 课程业务交互

- 课表为周一～周五、每日固定 10 节（默认列标：早、1～4、午、5～7、服；完整名可在改名 Sheet 中编辑）；节次结构不可增删。课表矩阵须在课程页一屏内完整显示、无需纵向滚动。轻点格打开课表格 Sheet（小字「课表」，大字「周X · 节次」）编辑科目文案（≤40 字）或清除；长按节次名打开节次改名 Sheet。课表格与节次名上的横滑须能触发主页面切页（不得因防误触 Sheet 跟手而整段 `blocked`）；有效横滑后抑制本次 click，轻点仍打开编辑。
- 成绩表列出全部学生与科目列；轻点分数格打开成绩 Sheet（小字为科目名，大字为学生姓名）与内置数字键盘，版式与登记页学生记录计分 Sheet 对齐（状态行、大号分数、键盘与清除/保存）；规则与登记计分相同（`0～100`、最多一位小数）；可清除单格。课程成绩与登记作业分数完全独立。保存/清除/关闭须在 `pointerdown` 立即生效，并短暂吞掉随后落在底栏、分段或成绩格上的幽灵点击，避免误切到课表或其他主页面。
- 长按科目表头打开科目编辑 Sheet：可改名或删除；至少保留 1 个科目，删除须经确认（标题「删除科目」）。
- 课程页“更多”：课表子视图显示「清空本周课表」「高亮科目」；成绩子视图显示「新增科目」「清空成绩」；主题切换始终可见。新增默认标题「新科目」。清空课表/成绩须经确认，不清空节次或科目本身。
- 「高亮科目」打开底部 Sheet：用顿号/逗号/换行配置关键词（字符串包含匹配，大小写不敏感）；命中的已填课表格使用淡蓝弱强调，不得使用高饱和大块色。关键词写入 `teacher-workbench.highlight-subjects`，不进入业务 Schema。
- Escape / 系统返回优先关闭确认面板，再关闭课程相关 Sheet（高亮科目 → 科目编辑 → 节次改名 → 课表格 → 成绩），再进入既有关闭栈。

## 5. 网格字号

- 登记页点击顶栏“更多”打开更多菜单；网格视图显示“姓名字号”，点击后关闭更多菜单并打开姓名字号。再次点击“更多”或点菜单外区域关闭。
- 座位视图的更多菜单不显示姓名字号，提供座位编辑与复位；人员页“更多”提供主题与按子视图的班干/值日操作（新增、清空指派）；课程页“更多”提供主题与按子视图的课表/成绩操作（清空课表、高亮科目、新增科目、清空成绩）。
- 字号滑杆范围为 `14～18px`、步长 `1px`，拖动和键盘调整时实时更新姓名字号及数值输出。
- 每次有效调整立即写入持久化；刷新后恢复上次字号。
- 点击姓名字号外部、切换页面 / 子视图或按 `Escape` 时关闭；滑杆手势不得触发横向切页。
- 姓名字号开关不持久化，刷新后始终关闭。

## 6. 座位画布与编辑

- 座位表包含 13×8、共 104 个逻辑位置，仅渲染 46 张已安排学生卡；学生与座位索引必须来自业务 Store 的同一份数据。
- 查看模式中轻点、长按/右键与网格等价；从卡片拖动转为画布平移，空白区域用于平移，双指与滚轮用于缩放；平移与双指缩放的命中范围覆盖整个座位视口（含舞台缩放后四周留白），均不得触发主页面导航。
- 编辑模式中拖到空位移动，拖到占用位置交换；目标位置高亮。pointer up、cancel、lost capture、模式切换和卸载必须清除临时 transform 与高亮。
- 画布 transform 与编辑模式仅在当前会话中保留；显式复位恢复默认位置和缩放，刷新后恢复查看模式和默认画布。快速平移可有惯性，reduced-motion 下跳过惯性。

## 7. 水平与垂直手势

轴锁定规则：移动超过 6px 后，以绝对位移较大的方向锁轴，本次手势中不再改变。

### 水平拖动

- 内容区横拖时页面实时跟手，glider 同步指向将进入的页面，且均不播放 transition。
- 底部导航横拖时 glider 以 1:1 位移跟随手指，内容页按“滑块跨一段对应内容跨一页”的进度实时联动；向左拖选择前一段，向右拖选择后一段。每当最接近的段索引变化时触发一次触觉反馈（边缘夹取后不重复震）。
- 人员页与课程页的分段控件（`.segments`）内横拖只操控 `.segment-glider`，不得触发主页面切页；规则对齐底栏：1:1 跟手、边缘阻尼、松手按最近段落位，段位变化时轻触反馈。点击分段按钮仍可直接切换子视图。
- 点击底栏导航按钮（切页或登记页重复点击切换子视图）触发一次触觉反馈。
- 第一页向右、最后一页向左时应用边缘阻尼，不能露出空白页。
- 底栏 glider 在第一段继续向左、最后一段继续向右时应用同样的边缘阻尼。
- 松手后根据距离或快速甩动决定是否切换；内容区最多切换相邻 1 页，底栏按滑块松手时最接近的段位落位，并允许一次横跨首尾页。
- 未达到阈值时回弹到当前页。

### 内容区垂直拖动

- 默认纵向移动当前 `.page` 的 `scrollTop`，不触发横向切页。
- 登记页网格视图：在应用全屏表面（顶栏、主内容区、底栏）向下拖使作业 Sheet 与遮罩跟手滑入，向上拖使通用菜单与遮罩跟手滑入；上下触发区域一致且全屏可用。松手后按进度/距离/甩动决定落位或回弹；打开作业不加振，打开通用菜单轻触反馈。
- 浏览器不得在手势中途接管并取消 pointer 序列。

### 纵向 Sheet 全屏跟手

- 适用范围（均为 `translateY` Sheet，与 `scripts/sheet-drag.js` 的 `SHEET_STACK_ORDER` 一致）：确认面板、高亮科目、课程科目/节次/课表格/成绩、人员编辑、人员选择、作业名称、作业列表、学生记录、通用菜单。更多菜单与姓名字号不在此列。
- 任一上述 Sheet 呈现时：除自滚动容器（且该方向尚未到边）与文本输入控件外，全屏任意位置均可纵向拖动，实时驱动该 Sheet 的 progress（0～1）与遮罩透明度；把手不再是唯一关闭入口。
- 例外：人员选择 Sheet 的学生名单使用原生纵向滚动；跟手关闭仅从把手/标题等非列表区域发起（见 §4.1）。
- 多层同时存在时只驱动最上层（顺序与返回键关闭栈一致，见 §10）；同一次手势不转移到下层。
- 松手：已打开 Sheet 慢拖关闭须位移约 `max(180px, 行程 40%)`；快速向外甩动时结合速度与惯性，短距离（约 36px+、关闭向速度约 `0.4px/ms`）亦可关闭。打开态按约 34% / 58px / 甩开阈值。`pointercancel` 等中断时已打开 Sheet 回弹。面板/列表/遮罩用 `touch-action: none`（人员选择名单除外，保留原生滚动），其余列表滚动由脚本接管。落位用 CSS transition；`prefers-reduced-motion: reduce` 时直接到位。跟手位移按动画帧合并绘制（`translate3d`），避免每 pointermove 重复触发布局。
- 有纵向 Sheet 呈现或跟手进行中时，禁止横向切页。
- 手势打开的 Sheet 关闭/取消时不得把焦点还回顶栏标题；程序化焦点使用静默聚焦（不显示 `:focus-visible` 环）。半程回弹落位不得再次触发打开时的抢焦点。

### 底部导航上滑

- 底栏上滑仍可打开通用菜单（与全屏上滑同一跟手/落位规则）；登记网格下底栏下滑也可打开作业列表；点击左上角菜单打开不加振、不走跟手。
- 手势过程中不显示上滑/下滑引导提示。

### 点击抑制

有效拖动或 Sheet 跟手后约 450ms 内抑制 click（勿用 microtask 立刻解除）。遮罩关闭须避开 Sheet `isActive`。不得删除该保护。

## 8. 触觉反馈

所有触觉统一为 `10ms`，由 `scripts/haptics.js` 的 `Haptic.light` / `Haptic.medium`（同为 `10`）与 `haptic()` 提供；业务代码禁止直接写 `navigator.vibrate` 毫秒数。不可用或抛错时静默降级。

| 场景 | 调用 |
| --- | --- |
| 底栏按钮、底栏越段、分段控件越段、完成切换、字母索引切换字母、底栏或登记网格全屏上滑打开通用菜单 | `haptic(Haptic.light)` |
| 长按打开打分、保存分数成功、确认面板「确认」 | `haptic(Haptic.medium)` |

在 Capacitor Android 壳内：只通过 `@capacitor/haptics` 的 `vibrate({ duration: 10 })` 发振，**不得**再调用 `navigator.vibrate`；原生 WebView / 控件默认 haptic 须关闭，避免系统层与 JS 各震一次。纯 Web（LAN / 浏览器）仍只用 `navigator.vibrate(10)`。

不在以下场景振动：更多菜单开合、作业列表开合、Toast、校验失败、取消、内容区滑页过程中的连续振动、点击菜单按钮打开通用菜单。

## 9. 通用菜单

打开方式：

- 点击左上角“菜单”。
- 从底部导航向上滑过阈值。
- 登记页网格视图全屏向上滑过阈值（与下滑打开作业同一全屏区域）。

关闭方式：

- 点击关闭按钮。
- 点击遮罩。
- 按 Escape 或系统返回键（仅当通用菜单为当前最上层时）。
- 全屏纵向跟手拖至关闭阈值或向外甩动；未达阈值或手势取消时回弹。

打开后必须同时：

- `state.drawerOpen === true`（字段名保留）。
- `.app` 具有 `.drawer-open`。
- 通用菜单 `aria-hidden="false"`。
- 由按钮打开时焦点静默移到关闭按钮（不显示焦点环）且不导致滚动；由手势打开时不抢焦点、关闭时不把焦点还回顶栏标题。

关闭后反向恢复，并清除拖动产生的行内 transform 和 `.dragging`。

## 10. 更多菜单与 Toast

- 登记页“更多”打开更多菜单：所有登记视图提供主题和清除当前作业；网格额外提供姓名字号，座位额外提供编辑模式与座位视图复位。通用菜单与 `activeOverlay` 业务浮层（作业列表、学生记录、人员/课程 Sheet、更多、确认等）必须互斥。
- Escape 与 Android 系统返回键共用同一关闭栈（`scripts/system-back.js`，与 `SHEET_STACK_ORDER` / `specs/04-terminology.md` 一致），按最上层优先关闭并恢复触发焦点：确认面板 → 高亮科目 → 科目编辑 → 节次改名 → 课表格 → 成绩 → 人员编辑 → 人员选择 → 作业名称 → 作业列表 → 学生记录 → 更多菜单 → 姓名字号 → 通用菜单。无浮层可关时，系统返回键退出应用。
- Toast 使用 `role="status"`，显示约 1600ms。
- 新消息到来时替换旧消息并重新计时；不得叠加多个 Toast。

## 11. 可访问性与输入

- 原生交互优先使用 `<button>`，不可用可点击 `<div>` 代替。
- 纯装饰 SVG 使用 `aria-hidden="true"`；无可见文案的按钮必须有 `aria-label`。
- 当前主导航项维护 `aria-current="page"`；通用菜单和姓名字号维护 `aria-hidden`，“更多”维护 `aria-expanded`。
- 无可见文字的主导航项必须用 `aria-label` 提供页面名称。
- 键盘可触发所有按钮和字号滑杆；Escape 与系统返回键须能关闭当前最上层浮层（见「更多菜单与 Toast」关闭栈）。
- 不阻止非必要的键盘默认行为。
- 新增定时动效或位移动效时，必须兼容 reduced motion。

## 12. 必测场景

1. 首屏落在“登记 / 网格”，glider 和所有 active 状态一致。
2. 连续左右滑到两端，索引不越界且边缘有阻尼。
3. 慢拖未过阈值回弹；快速甩动切换一页。
4. 页面纵向滚动不误切页。
5. 点击当前底导航两次，子视图来回切换，指示点同步；登记页无需分段控件也可往返网格 / 座位；人员/课程分段轨道内横滑只切子视图。
6. 网格视图点击“更多”后从更多菜单打开姓名字号，实时调整字号；刷新恢复该值，两个浮层均保持关闭。
7. 座位视图“更多”显示编辑与复位；人员页“更多”显示主题与班干/值日操作；课程页“更多”显示主题与课表/成绩操作（含高亮科目）；姓名字号在人员/课程/座位均不可见。
8. 打开通用菜单后不能触发背后的页面手势；四种关闭方式均有效。
9. 登记页字母条：落稳后渐显；主页面横移立刻渐隐；按住字母高亮匹配学生并轻触反馈；松手后约 400ms 清除；字母条手势不触发切页或打开作业/菜单。
10. 课表格区域横滑可切主页面；轻点仍打开编辑。连续触发多条 Toast（如复制未交、保存成功）时只显示最后一条。

# 02 · 交互与状态 Spec

## 1. 状态模型

状态分为 UI 瞬时状态与业务 Store 两个边界。`scripts/state.js` 只保存 UI 状态：

```text
currentPage: 0 | 1 | 2
subviews: [0 | 1, 0 | 1, 0 | 1]
suppressNavClick: boolean
drawerOpen: boolean
studentFontSize: 14 | 15 | 16 | 17 | 18
fontSizePopoverOpen: boolean
seatEditing: boolean
activeOverlay: null | 'assignments' | 'student-record' | 'more' | 'confirm'
```

`roster-store.js` 是学生、座位、作业、提交和分数的唯一可写来源；网格和座位渲染器只订阅它，禁止双写领域数组。

约束：

- `currentPage` 必须经过 `clampPage()`，不可越界。
- 每页独立记住本次会话中的子视图选择。
- 导航、子视图、抽屉和字号浮层状态只存在内存；刷新后回到产品 Spec 定义的初始状态。
- `studentFontSize` 使用 `teacher-workbench.student-name-font-size` 保存；读取失败或非数值时回退到 `16`，越界数值按 `14～18` 夹取。业务数据和主题的受控持久化规则见工程 Spec。
- CSS class 和 CSS 自定义属性是状态的渲染结果，不是第二份状态源。

## 2. 主页面导航

用户可通过两种方式切换主页面：

1. 点击底部的另一个导航项，直接进入目标页。
2. 在内容区水平拖动，按内容轮播方向切换相邻页；在底部导航上水平拖动，则直接操控三段式 glider 选择相邻页。

当前导航项被再次点击时，不停留不动，而是切换该页的两个子视图。这是既定功能，不能“修正”掉。

每次渲染必须同步：

- `.pages` 的横向位置。
- `.nav-glider` 的位置。
- 顶栏标题：人员页与课程页显示页面名称，登记页始终显示当前活动作业名称；从其他页面切回登记时必须立即刷新，不得保留上一页标题。
- 导航按钮 `.active` 和 `aria-current="page"`。
- 存在分段控件的页面中，segment 的 `.active`。
- 每页 subview 的 `.active`。
- 每个导航项的子视图指示点 `.on`。

## 3. 子视图

- 点击分段按钮只切换其所属页面的子视图，不切换主页面。
- 人员页和课程页始终恰好 1 个 segment 与 1 个 subview 为 active。
- 登记页不显示 segment，重复点击当前“登记”导航项在网格 / 座位间切换，并由 subview 与指示点表达状态。
- 切换主页面后，该页恢复到本次会话最后选择的子视图。

## 4. 登记业务交互

- 活动作业属于业务 Store。网格和座位卡的轻点只切换当前作业的完成状态；完成与分数按 `(assignmentId, studentId)` 唯一，分数存在即视为完成。
- 长按约 `480ms`、桌面右键打开同一学生记录面板；移动超过 `9px`、结束、取消或离开均取消长按，成功长按必须抑制同一指针序列的 click。可用时可调用 `navigator.vibrate(18)`，不可用时静默降级。
- 长按打开学生记录面板即视为打分意图：面板直接显示学生姓名、分数框和内置数字键盘，不再提供二次模式选择或唤起系统软键盘。键盘支持 `0～9`、小数点和退格，只允许形成 `0～100` 且最多一位小数的草稿；保存与清除规则不变。仅提交仍由网格或座位卡轻点完成。面板顶部提供手势提示条，从提示条向下拖动超过 88px 关闭，未超过阈值或手势取消时回弹。
- 顶栏登记标题显示活动作业名称，点击打开作业列表；列表显示已交人数/总人数，支持选择、新增、重命名和删除，至少保留一个作业。删除活动作业后选择相邻可用作业。
- 改名使用应用内「修改作业名称」浮层：预填当前名称、取消/保存、点遮罩或 Escape 关闭；Enter 保存；校验失败以 Toast 提示。新增作业仍可使用系统 `prompt`。删除成功后以 Toast 确认。关闭作业面板时须先关闭改名浮层。Escape 优先关闭改名浮层，再关闭作业面板。
- 通用菜单的全部标记、清除、复制未交名单只作用于活动作业；恢复默认名单和座位须先确认。复制未交名单用中文顿号连接，全部已交时不得写入空文本。

## 5. 网格字号

- 登记页点击顶栏“更多”打开上下文更多面板；网格视图显示“姓名字号”，点击后关闭更多面板并打开字号浮层。
- 座位视图的更多面板不显示姓名字号，提供座位编辑与复位；人员页和课程页点击“更多”显示“更多功能即将推出”Toast。
- 字号滑杆范围为 `14～18px`、步长 `1px`，拖动和键盘调整时实时更新姓名字号及数值输出。
- 每次有效调整立即写入持久化；刷新后恢复上次字号。
- 点击浮层外部、切换页面 / 子视图或按 `Escape` 时关闭浮层；浮层自身的滑杆手势不得触发横向切页。
- 字号浮层开关不持久化，刷新后始终关闭。

## 6. 座位画布与编辑

- 座位表包含 13×8、共 104 个逻辑位置，仅渲染 46 张已安排学生卡；学生与座位索引必须来自业务 Store 的同一份数据。
- 查看模式中轻点、长按/右键与网格等价；从卡片拖动转为画布平移，空白区域用于平移，双指与滚轮用于缩放，均不得触发主页面导航。
- 编辑模式中拖到空位移动，拖到占用位置交换；目标位置高亮。pointer up、cancel、lost capture、模式切换和卸载必须清除临时 transform 与高亮。
- 画布 transform 与编辑模式仅在当前会话中保留；显式复位恢复默认位置和缩放，刷新后恢复查看模式和默认画布。快速平移可有惯性，reduced-motion 下跳过惯性。

## 7. 水平与垂直手势

轴锁定规则：移动超过 6px 后，以绝对位移较大的方向锁轴，本次手势中不再改变。

### 水平拖动

- 内容区横拖时页面实时跟手，glider 同步指向将进入的页面，且均不播放 transition。
- 底部导航横拖时 glider 以 1:1 位移跟随手指，内容页按“滑块跨一段对应内容跨一页”的进度实时联动；向左拖选择前一段，向右拖选择后一段。
- 第一页向右、最后一页向左时应用边缘阻尼，不能露出空白页。
- 底栏 glider 在第一段继续向左、最后一段继续向右时应用同样的边缘阻尼。
- 松手后根据距离或快速甩动决定是否切换；内容区最多切换相邻 1 页，底栏按滑块松手时最接近的段位落位，并允许一次横跨首尾页。
- 未达到阈值时回弹到当前页。

### 内容区垂直拖动

- 纵向移动当前 `.page` 的 `scrollTop`。
- 不触发横向切页或打开抽屉。
- 浏览器不得在手势中途接管并取消 pointer 序列。

### 底部导航上滑

- 上滑超过提示阈值时显示“继续上滑，打开通用菜单”。
- 上滑超过打开阈值后松手，打开抽屉。
- 提示在结束或取消手势时隐藏。

### 点击抑制

发生有效拖动后，短时间抑制 click，防止松手误触导航按钮。不得删除该保护。

## 8. 抽屉

打开方式：

- 点击左上角“菜单”。
- 从底部导航向上滑过阈值。

关闭方式：

- 点击关闭按钮。
- 点击遮罩。
- 按 `Escape`。
- 下拉抽屉把手超过 88px；未超过阈值或手势取消时回弹。

打开后必须同时：

- `state.drawerOpen === true`。
- `.app` 具有 `.drawer-open`。
- 抽屉 `aria-hidden="false"`。
- 焦点移动到关闭按钮且不导致滚动。

关闭后反向恢复，并清除拖动产生的行内 transform 和 `.dragging`。

## 9. 更多面板与 Toast

- 登记页“更多”打开上下文更多面板：所有登记视图提供主题和清除当前作业；网格额外提供姓名字号，座位额外提供编辑模式与座位视图复位。抽屉、更多、学生记录、作业与确认面板必须互斥，Escape 按最上层浮层优先关闭并恢复触发焦点。
- Toast 使用 `role="status"`，显示约 1600ms。
- 新消息到来时替换旧消息并重新计时；不得叠加多个 Toast。

## 10. 可访问性与输入

- 原生交互优先使用 `<button>`，不可用可点击 `<div>` 代替。
- 纯装饰 SVG 使用 `aria-hidden="true"`；无可见文案的按钮必须有 `aria-label`。
- 当前主导航项维护 `aria-current="page"`；抽屉和字号浮层维护 `aria-hidden`，“更多”维护 `aria-expanded`。
- 无可见文字的主导航项必须用 `aria-label` 提供页面名称。
- 键盘可触发所有按钮和字号滑杆；抽屉与字号浮层必须支持 Escape。
- 不阻止非必要的键盘默认行为。
- 新增定时动效或位移动效时，必须兼容 reduced motion。

## 11. 必测场景

1. 首屏落在“登记 / 网格”，glider 和所有 active 状态一致。
2. 连续左右滑到两端，索引不越界且边缘有阻尼。
3. 慢拖未过阈值回弹；快速甩动切换一页。
4. 页面纵向滚动不误切页。
5. 点击当前底导航两次，子视图来回切换，指示点同步；登记页无需分段控件也可往返网格 / 座位。
6. 网格视图点击“更多”后从上下文面板打开字号浮层，实时调整字号；刷新恢复该值，两个浮层均保持关闭。
7. 座位视图“更多”显示编辑与复位，人员页和课程页“更多”显示占位 Toast；字号浮层均不可见。
8. 打开抽屉后不能触发背后的页面手势。
9. 抽屉四种关闭方式均有效。
10. 连续点击多个占位操作，只显示最后一条 Toast。

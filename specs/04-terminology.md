# 04 · 界面命名对照

本表定义当前教师工作台 Demo 的统一称呼，供需求、评审与开发沟通使用。名称描述界面职责，不替代现有 DOM class、ID 或 data 属性；代码改动仍须遵守 `ARCHITECTURE.md` 和工程 Spec 中的 DOM 契约。

## 1. 全局框架

| 沟通名称 | 对应元素 / 标识 | 说明 |
| --- | --- | --- |
| 应用外壳 | `#app.app` | 整个手机工作台容器。 |
| 应用顶栏 | `.topbar` | 最上方的三列操作栏。 |
| 菜单按钮 | `#menuButton` | 顶栏左侧的“菜单”触发器。 |
| 顶栏标题 | `.topbar-title` | 顶栏中间的“工作台”。 |
| 更多按钮 | `#moreButton` | 顶栏右侧的“更多”触发器。 |
| 内容视口 | `#viewport.viewport` | 承载横向页面手势的可视区域。 |
| 页面轨道 | `#pages.pages` | 三个主页面组成的横向移动容器。 |
| 主页面 | `.page[data-page]` | 页面轨道中的一个纵向可滚动页面。 |
| 页面内容内层 | `.page-inner` | 单个主页面内除滚动容器外的内容排版层。 |
| 页面眉题 | `.eyebrow` | 页面标题上方的英文/中文辅助标签。 |
| 页面主标题 | `.page h1` | “安排”“登记”“课程”三个页面标题。 |
| 页面摘要 | `.summary` | 页面主标题下方的功能说明。 |
| 子视图切换器 | `.segments` | 每个主页面中的两项分段控件。 |
| 子视图按钮 | `.segment[data-sub]` | 切换该页面子视图的单个按钮。 |
| 子视图内容 | `.subview[data-view]` | 与一个子视图按钮对应的内容组。 |

## 2. 主页面与子视图

| 主页面 | `data-page` | 子视图（`data-view` / `data-sub`） | 统一简称 |
| --- | ---: | --- | --- |
| 安排页 | `0` | `0` 班干 | 班干视图 |
| 安排页 | `0` | `1` 值日 | 值日视图 |
| 登记页 | `1` | `0` 网格 | 网格视图 |
| 登记页 | `1` | `1` 座位 | 座位视图 |
| 课程页 | `2` | `0` 课表 | 课表视图 |
| 课程页 | `2` | `1` 成绩 | 成绩视图 |

提及某个子视图内部元素时，使用“**[子视图简称] + 元素名称**”的格式，例如“座位视图 Hero 卡片”“成绩视图内容卡片”。

## 3. 子视图内容组件

以下元素在六个子视图中结构一致；仅文案和 Hero 颜色变体不同。

| 沟通名称 | 对应元素 / 标识 | 说明 |
| --- | --- | --- |
| Hero 卡片 | `.hero-card` | 子视图最主要的概览卡片；橙色、深色、默认色是其现有视觉变体。 |
| Hero 标签 | `.hero-label` | Hero 卡片内标示当前子视图的短标签。 |
| Hero 主值 | `.hero-value` | Hero 卡片中当前显示“页面占位”的主信息。 |
| Hero 说明 | `.hero-note` | Hero 主值下的功能说明。 |
| 进度条 | `.progress` | Hero 卡片底部的整体进度组件。 |
| 进度填充 | `.progress > i` | 由 `--progress` 控制长度的进度条前景。 |
| 内容区标题 | `.section-title` | Hero 卡片下方的“班干内容”等区块标题。 |
| 待完善标记 | `.section-title span` | 内容区标题内的状态文字。 |
| 内容卡片 | `.card` | 当前子视图的普通信息卡片。 |
| 内容行 | `.card .row` | 内容卡片内的一行布局。 |
| 功能字图标 | `.icon` | 内容行左侧的单字功能标记。 |
| 内容文案组 | `.grow` | 内容行右侧、占满剩余宽度的文字容器。 |
| 内容项标题 | `.item-title` | 内容文案组的主标题。 |
| 内容项说明 | `.item-note` | 内容文案组的辅助说明。 |

## 4. 底部导航与手势提示

| 沟通名称 | 对应元素 / 标识 | 说明 |

| 上滑提示 | `#gestureTip.gesture-tip` | 从底部导航上滑至提示阈值后显示的引导文字。 |

## 6. 状态名称

| 状态名称 | 状态来源 / 表现 | 含义 |
| --- | --- | --- |
| 当前主页面 | `state.currentPage`、导航项 `.active` | 当前展示的安排、登记或课程页。 |
| 当前子视图 | `state.subviews`、分段按钮和子视图 `.active` | 每个主页面在本次会话内记住的已选子视图。 |
| 导航激活态 | `.nav-btn.active`、`aria-current="page"` | 与当前主页面对应的导航项状态。 |
| 分段激活态 | `.segment.active` | 与当前子视图对应的分段按钮状态。 |
| 内容激活态 | `.subview.active` | 当前可见的子视图内容状态。 |
| 指示点选中态 | `.subdots i.on` | 当前子视图对应的圆点状态。 |
| 拖动中 | `.pages.dragging`、`.nav-glider.dragging` 或 `.drawer.dragging` | 手势跟手阶段，临时取消过渡动画。 |
| 菜单打开态 | `state.drawerOpen`、`.app.drawer-open`、`#drawer[aria-hidden="false"]` | 抽屉已打开、遮罩生效且焦点移至关闭按钮。 |
| Toast 显示态 | `#toast.toast.show` | Toast 正在显示；新消息会替换旧消息并重新计时。 |
| 导航点击抑制态 | `state.suppressNavClick` | 有效拖动结束后的短暂保护，防止松手误触导航项。 |

## 7. 初始画面称呼

刷新后的默认画面称为“**登记页 / 网格视图首屏**”：`currentPage` 为 `1`，三个页面均选中各自的第一个子视图，通用菜单关闭，Toast 隐藏。

# 拇指移动端交互 Demo

纯 HTML / CSS / JavaScript 的移动端多页面交互演示。

## 运行

双击 `start-lan-server.bat` 即可启动零依赖局域网服务器。终端会显示本机和局域网访问地址；手机与电脑连接同一 Wi‑Fi 后访问该地址即可。

也可以直接在浏览器打开 `index.html`，或使用任意静态服务器预览。

## 操作

- 点击底部三段导航切换主页面；再次点击当前项切换其子视图。
- 在内容区或底部导航左右拖动，超过阈值后切换相邻页面。
- 在底部导航明显向上滑动，或点击右侧“菜单”按钮，打开通用抽屉。
- 点击遮罩、关闭按钮或向下拖动抽屉关闭菜单。
